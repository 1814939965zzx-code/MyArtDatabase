# artDatabase 当前需求

> 本文档是当前产品规则的唯一入口。历史版本仅供追溯，不得覆盖本文档。
> 本文只描述产品行为与用户可见规则，不记录文件、接口、表结构、库与参数等实现细节；实现事实统一由 AOCI 认知索引维护（见 §5）。
> 最后整理：2026-11-12

## 1. 产品范围

artDatabase 是面向团队的图片素材库。素材存放在全局素材库中，项目通过引用组织素材；全局标签用于跨项目检索，维度 Page 用于分组排序和对比，自由画板用于空间化整理素材。

MVP 约束：

- 支持**图片与视频**素材：图片上传后自动生成缩略图；视频上传后由服务端**自动转码**为可播放的低码率 MP4，转码成功后删除原始文件。不支持音频单独素材。
- 通过局域网提供服务，**已启用账号系统**（见 §3.9）：不提供公开注册，首次启动引导创建管理员，之后仅管理员可增删成员。
- 不支持批量上传，不要求自动备份。
- 不提供图片裁剪、调色、加字等在线编辑。
- 不记录 Metadata 历史版本。

## 2. 核心模型

- **全局素材**：一份图片或视频文件、一条素材主记录和一份唯一 Metadata，可同时被多个项目引用。视频只保存转码后的产物，不保留原始文件。
- **项目**：一级分类，只保存素材引用；删除项目不能删除全局素材。
- **全局标签**：素材级标签，人工输入或 AI 生成；存于独立标签字典，同一标签在所有素材间复用，修改后同步影响所有项目引用。
- **维度 Page**：项目下独立的维度画板，各自引用项目素材、管理维度和素材维度值；同一素材可加入多个 Page。维度由左右端名称和连续数值组成，各 Page 互不影响。
- **自由画板**：项目下的无限画布；Frame 为可选容器，素材以实例组织，另含一个覆盖全部图层的可开关草稿标记图层（文本与描边图形）。

Metadata 字段：

| 字段 | 来源 | 要求 |
| --- | --- | --- |
| 素材名称 | 用户可编辑 | 必填；上传时默认为去扩展名文件名 |
| 全局标签 | 用户可编辑；AI 可自动生成 | 可空；单素材上限 50 个 |
| 描述、备注、来源链接 | 用户可编辑 | 可空 |
| 上传时间、原始文件名、文件大小、图片尺寸、格式 | 系统生成 | 只读 |
| 时长 | 系统生成 | 图片为空；视频为转码后时长，转码完成前为空 |

数据表结构、存储布局与接口契约不再在本文维护，见 §5。

## 3. 当前有效行为

### 3.1 项目与素材

- 登录后进入**主页**（Figma 式）：左侧为导航栏（项目/全部素材/标签管理/新建项目/已归档项目/回收站），右侧主区为项目卡片网格；卡片显示封面拼图（项目内最多 4 张素材缩略图，无素材时显示占位图标）、名称、说明与素材/维度数量，hover 卡片提供“重命名”“归档”和“删除”操作（hover 保留描边、投影与封面缩略图轻微放大，不做上浮动画，与素材卡一致）；顶栏搜索按项目名称/说明过滤；主页不包含素材详情、上传等项目内功能。
- 点击项目卡片进入**项目工作区**：左侧导航收起，左上角提供“返回主页”按钮；项目内三个视图页签（“维度预览 → 自由画板 → 素材库”）置于最顶部顶栏内、紧随“返回主页/项目名”居左显示（与标题间以竖向分割线相隔）；素材详情抽屉、图片上传（文件/拖拽/剪贴板）只存在于项目内。
- 支持创建、重命名、归档和删除项目（主页卡片与项目内顶栏均可进入项目设置）；删除项目立即从列表隐藏，并提供 5 秒撤销条，5 秒后提交服务端删除。
- 已归档项目从主页和默认项目列表隐藏，左侧导航“已归档项目”（位于回收站上方）中展示；归档不删除任何素材、维度或画板，可在该页恢复项目或删除项目。删除归档项目采用 5 秒撤销条，确认后清空该项目相关的维度、Page、画板、项目引用等数据；全局素材文件保留。
- 支持全局素材库和项目素材的网格浏览（不再提供列表视图）。
- 全部素材页与项目素材页的工具栏提供“卡片宽度”滑块，可在 `240～400px` 之间动态调整素材卡宽度（默认 `400px`），列数随宽度与窗口宽度自动变化（不设列数上限）；设置会被记住并在两处共用。
- 素材网格按卡片宽度等分可用宽度自动决定列数：窗口越宽列数越多（宽屏不再固定 4 列），列间距 17px、余量平均分给每张卡片；620px 及以下窄屏保持 2 列。
- 全部素材页与项目素材页的素材卡片：左上角用图标标签区分素材类型（图片 / 视频），不再显示序号；hover 保留描边、投影与图片轻微放大（只过渡 transform），不做卡片整体位移或对比度过渡。
- 项目素材库顶栏右侧提供“从全部素材导入”按钮：打开全局素材多选面板（可按名称、文件名、标签搜索与筛选），当前项目已引用的素材置灰；确认后为选中素材建立项目引用（首次加入时维度值默认位于中点），不复制文件。
- 项目素材库提供“批量选择”：可逐个勾选素材，或按当前筛选结果全选；选择后一次“从当前项目移除”所选素材，只解除项目引用，不删除全局素材；切换搜索词、标签筛选或收藏分类时清空已选，避免误删当前看不见的素材。
- 项目素材库与全部素材库的素材详情支持左右箭头切换素材：按打开详情时当前筛选结果的顺序切换，切换前自动保存当前素材修改，首尾对应箭头禁用；自由画板打开的详情不提供该切换。
- 支持按素材名称、原始文件名、标签和引用项目搜索。
- 全部素材页展示全部全局标签；标签筛选为多选，选中多个标签时按 OR 组合，并与关键词按 AND 组合。
- 项目素材页新增标签筛选模块，默认展示该项目素材包含的全部标签，筛选同样为多选并按 OR 组合。
- 项目素材页提供“全部素材 / 收藏”两个分类页签并显示数量；收藏按项目独立维护，同一素材加入多个项目时各项目的收藏互不影响；关键词与标签筛选在收藏分类内继续生效，收藏分类为空时显示空状态引导。
- 项目素材库与全部素材库共用同一标签筛选模块：默认展示 2 行、超出可展开收起，已选中的标签排最前；全部素材页的卡片宽度控制独立一行位于标签卡片下方靠右，标签管理入口位于顶部搜索栏左侧。
- 项目视图页签顺序为“维度预览 → 自由画板 → 素材库”，进入项目后默认打开维度预览。
- 项目中的素材是全局素材引用；“从项目移除”只删除引用。
- 项目内素材详情（维度预览、自由画板、素材库共用）标题栏提供收藏按钮，点击立即切换星标并保存到当前项目；全局素材库详情不提供收藏入口。已收藏素材在项目素材卡片右上角显示星标；项目素材库进入批量选择时星标临时隐藏，右上角改为选择复选框。
- 素材详情顶栏右上角把“i”信息图标与收藏、关闭按钮放在同一组：文件名、上传者、尺寸/时长、文件大小与格式收进“i”，hover（或键盘聚焦、点击）在图标下方弹出只读信息卡，悬浮时面板其余内容压暗；详情正文不再单独显示这几行。
- 素材详情中不裁切原图，图片在可用宽高内等比例完整展示；视频素材在详情内嵌播放器播放，信息卡中显示时长。
- 全局详情和项目详情均可编辑名称、全局标签、描述、来源链接和备注；所有文本输入必须支持普通空格和中文输入法组合输入。
- 来源链接默认以只读链接展示，点击后在新标签页打开；无链接时使用“增加”进入输入状态，已有链接时使用“编辑”修改，跳转只允许 `http://` 和 `https://`。
- 已有素材可以通过文件选择或在详情打开时粘贴剪贴板图片进行替换；确认前展示新旧图片对比，并可用 `Ctrl/Command + Z` 撤销待替换图片。替换只更新图片文件及其系统生成信息，素材 ID、Metadata、项目引用、维度值、画板元素和创建时间必须保持不变。
- 标签以左对齐、横向排列并自动换行的 Badge 展示；删除图标位于 Badge 左侧。新增标签使用单一输入框，输入时模糊匹配已有全局标签，也允许创建新标签。输入匹配到已有标签时，需用方向键上下选中建议项后按回车或空格插入；未选中时回车按输入原文添加（若原文与某待删除标签一致则撤销其删除状态）。
- 标签删除无需倒计时：点击删除图标（无论该标签是素材原有还是本次新添加）后标签原地变为删除线样式（红色），删除图标切换为撤销图标；再次点击可撤销。关闭详情时统一结算：保存的标签集合自动排除所有待删除标签，一次提交完成新增与删除。
- 详情中不再显示“保存素材信息”按钮；关闭按钮、遮罩和 `Esc` 都必须先自动保存已修改的 Metadata，校验或保存失败时保持详情打开。
- 详情打开时锁定背景页面滚动，右侧详情面板可以独立滚动。
- 光标语义统一：可操作元素（按钮、可点击的卡片与列表行、页签、标签 chip、勾选框、下拉与滑块）显示手型光标；禁用或当前不可操作的控件显示禁止光标，不显示手型；拖拽、画布与维度预览场景继续使用各自的专用光标（抓取、十字、缩放等）。

### 3.2 上传

- 支持文件选择、拖拽和剪贴板粘贴（剪贴板粘贴仅适用于图片），一次只上传一张。
- 图片支持 JPEG、PNG、WebP、GIF、SVG、TIFF、HEIC/HEIF、AVIF，单文件上限 50 MB；视频支持常见容器格式（mp4/mov/webm/mkv 等，编码不限，HEVC 亦可），单文件上限 200 MB。
- 上传前检测完全重复文件（按文件内容哈希）；用户可以引用已有素材或保留为新素材。
- 正式提交前编辑素材名称、全局标签、描述等素材信息；上传窗口不编辑维度值。
- 新上传的素材不自动加入任何维度 Page；加入 Page 后，该 Page 的各维度默认位于中点 `0`。
- 新素材自动加入当前项目；取消上传不得创建素材记录。
- 上传窗口显示**上传进度百分比**；浏览器无法预览的格式（如 HEIC）显示提示占位但仍可上传。
- 图片上传后由服务端自动生成缩略图；浏览器不支持原图显示时，详情大图回退到缩略图。
- **视频自动转码**（异步执行，不阻塞上传）：
  - 转码为低码率 MP4（720p 级、码率上限 2 Mbps），有音轨则保留音频；具体编码参数与队列实现见 AOCI（`app/server/transcode.js` 条目）。
  - **转码进度可视化**：转码期间列表卡片显示“转码中 X%”徽标、详情抽屉显示进度条并自动刷新。
  - 转码期间素材不可播放；成功后缩略图由转码产物生成、时长与尺寸等系统信息同步更新，进度满格；失败时保留原始文件，可重试或删除重传。
  - 服务重启时把未完成的转码任务标记为失败（原始文件仍在，安全）。
  - **删除原始文件只发生在转码成功且素材记录已切换到转码产物之后**；转码失败、中断或切换失败时必须保留原始文件。
  - 视频不参与 AI 打标（上传窗口与详情页对视频素材不显示 AI 打标入口）。

### 3.3 Page 维度

- 每个维度 Page 可以创建任意数量的维度；维度定义、名称和素材数值仅属于当前 Page，各 Page 完全独立。
- 一次预览最多选择三个维度：一个维度显示一维轴，两个显示二维平面，三个显示三维空间。
- 仅从维度 Page 打开的素材详情展示该 Page 的全部维度，不受预览上限影响；该入口的详情把维度位置（名称与 Slider）放在最前面，其余 Metadata 与替换入口排在其后；项目素材库、自由画板和全局素材详情均不显示维度编辑。
- 维度值在界面上为 `-100～100` 的连续整数，中点 `0` 表示中性位置。
- 素材加入 Page 或 Page 新增维度时，该 Page 对应数值默认位于中点 `0`。
- 从维度 Page 打开的素材详情通过维度 Slider 调整当前素材在该 Page 的位置，松开或失焦时保存。
- 每条维度右侧各有一个无文案的编辑图标按钮；点击后只编辑该维度的左右端名称，不影响外层 Slider。浮窗提供“取消”和“应用修改”，名称保存后只在当前 Page 的素材详情和维度预览中生效。
- 维度两端名称必填、各不超过 24 个字符，且去除首尾空格后不能相同；校验或应用失败时保持浮窗打开。
- 维度 Slider 步进为 1 个界面单位，强调色填充从轨道中点 `0` 向当前值延伸，不从最左端起算。
- 同一素材在同一 Page、同一维度下只能有一个值；名称、标签、描述等全局 Metadata 仍在所有引用中同步。
- 删除当前 Page 的维度时立即从预览、选中轴和素材坐标中移除，同时显示 5 秒撤销条；5 秒内撤销会恢复维度、选中顺序与全部坐标，5 秒后提交服务端删除，不影响其他 Page。撤销窗口内即使预览页被刷新，也不会把待删除维度带回来。

### 3.4 维度预览

- 一个项目可以创建多个维度 Page，支持切换、新建、重命名和删除；新项目自带一个空白 `Page 1`，后续新建 Page 均为空；删除 Page 立即从页签隐藏并切换，提供 5 秒撤销条，5 秒后提交服务端删除。
- 每个 Page 独立保存素材集合、维度定义、维度值和选中的最多三个坐标轴及其顺序，继续支持 1D / 2D / 3D。
- 通过“添加素材”打开项目素材选择面板，支持名称/文件名/标签搜索、标签多选 OR 筛选及多选加入；同一素材可加入多个 Page，同一 Page 内不可重复加入。
- 从当前 Page 的素材详情可移除该 Page 引用；移除素材或删除 Page 仅删除其对应的维度/数值/展示数据，不删除项目引用、全局素材或其他 Page 数据。
- 素材从项目移除时，同时清理它在该项目各维度 Page 的引用及数值；软删除素材时暂时隐藏，恢复后在原 Page 显示并保留数值。
- 旧项目在升级时一次性迁入“默认画板”，保留原有全部项目素材、维度及数值；重启不重复迁移，删除 Page 后不会自动恢复。
- 左侧“选择预览维度”面板中，维度项选中后不再使用对勾：按其选中顺序第 1/2/3 项分别以 `x`/`y`/`z` 字母标记，对应预览的横轴/纵轴/第三轴（与预览内 X/Y/Z 轴的分配一致）；未选中项仍显示其在列表中的序号。
- 三轴从中心向正负两端延伸并在中心相交，渲染为有厚度的 1px 细线（任意角度均可见）；轴端不绘制箭头，只用只读 tag（`faint` 浅灰实底、白字的圆角胶囊，与可点击的筛选 chip 区分）显示维度左右端名称；坐标轴不显示数值刻度。
- 坐标轴的角落同样用 tag 展示端点名称，且每个维度各一个独立 tag（2D 平面四角各两个 tag；3D 空间的 XY、XZ、YZ 三个平面四角各两个 tag，八个顶点各三个 tag），不同坐标不合并进同一个 tag；同一角落的多个 tag 作为一个整体朝向摄像机，旋转视角时不互相错位。2D 平面四角的 tag 组贴在平面外侧，内边缘与轴端点 tag 保持同样的 7px 端距（横轴 tag 对齐横轴端点 tag、纵轴 tag 对齐纵轴端点 tag），不占用象限区域；3D 顶点仍以顶点为中心。

- 1D/2D 拖动图片进入已有堆所在格子且各已选维度的正/负/零分区一致时，该堆放大并高亮；高亮判定与实际聚堆共用格子及符号分区规则。
- 1D/2D 可在平面内直接拖动卡片修改选中维度值（水平移动改第一维、垂直移动改第二维），3D 卡片只可点击打开详情；堆本身不可拖动、点击堆无动作。
- 未成堆的单张保留 hover 2.475 倍放大（整体放大后大小与原一致），通过屏幕前景层显示在最前，不隐藏前方遮挡物（含堆），改为按模糊开关统一模糊/压暗（关闭模糊时只保留白色叠加）；缩放视图（滚轮、捏合、工具栏缩放/重置）或图片缩放系数滑块导致聚堆合并/展开时，涉及素材以 200ms 位移动画从旧位置滑到新位置，堆内第 5 张之后的隐藏成员也以屏幕幽灵缩略图滑入新堆中心；其他操作导致的聚堆变化仍即时切换，不使用过渡动画。
- 开发构建在预览工具栏提供“调试”开关：开启后绘制每个堆实际所属的网格范围；该开关与绘制逻辑只存在于开发构建，生产构建不包含。

- 维度预览与自由画板均支持 Mac 触控板：双指滑动（含横向、纵向与惯性）平移视图，双指捏合缩放；普通鼠标滚轮直接缩放，无需按修饰键；按滚动单位、精细滚动特征与连续手势识别触控板平移，保留惯性连续性，明确的鼠标事件立即切回缩放。无法识别的大幅像素滚动在无近期触控板手势时默认按鼠标缩放；Ctrl/Command + 滚轮仍可显式缩放。兼容 Chrome/Edge 与 Safari 的捏合事件差异，避免重复缩放；仅在视图范围内阻止页面滚动与浏览器默认缩放。保留空格 + 左键、中键平移及工具栏缩放按钮。手势只改变视图，不修改素材、Frame 或标记坐标；展开平面在双指平移时保持展开、捏合时收起。

### 3.5 自由画板

- 自由画板采用无限画布，Frame 是**可选容器**：图片既可直接放在画布上，也可拖入某个 Frame 归属该 Frame。
- 新建 Page 默认是一块**空白无限画布**（不再自动生成任何固定尺寸 Frame）；可手动创建 Frame：点击工具条「新建 Frame」按钮进入创建态，在画布上按住左键拖出自定义大小与位置的 Frame（拖动中显示虚线预览，松手即创建并选中；坐标与尺寸自动取整对齐像素；误点/不足拖动不创建；Esc、切换工具或再次点击按钮取消创建态）；一个项目可创建、切换、双击重命名和删除多个 Page。
- 一个 Page 可有多个 Frame；Frame 可双击重命名，选中后可移动和从八个方向自由缩放，标题缩小时保持可读；标题栏不常驻显示尺寸，仅在该 Frame 被拖动（移动/缩放）时实时显示当前 `宽 × 高`；Frame 与图片一致，**按下即可直接拖动**（未选中的 Frame 在按下瞬间选中并进入拖动，纯点击仍只是选中）；**`Shift+点击` 可增删多选**，**多选后按住任一选中 Frame 拖动可整体平移全部选中 Frame，其内部元素同步位移并保存**；Frame 可与素材元素**混合多选**（框选或 `Shift+点击` 跨类型加选），混合选中后拖动任一成员（图片/标记/Frame）整组移动；删除方式：右键菜单删除单个，或框选多选后按 `Delete`/`Backspace`（或右下角“已选 N 个 Frame”工具条的删除）批量删除，**直接删除、不再弹确认**；删除 Frame 同时移除其中图片的画板布局，不删除项目素材或原文件，可用 `Ctrl/Command + Z` 撤销删除。
- 同一素材可在同一 Page 内重复放置，每次放置拥有独立元素 ID 和布局。
- 从左侧托盘拖入图片时按素材原图宽高比插入（缺失尺寸退回 3:4）；图片缩放不设最大/最小限制。
- 图片元素交互简化：不显示名称 caption，无旋转操作；右下角缩放把手在 **hover 或选中**时才显示；选中工具条保留置顶/置底与删除。
- 素材元素支持拖动、缩放、置顶、置底和移除；右键删除图片只移除当前画板实例。
- 在 Page 空白区域拖动可框选多张图片，`Shift` 可增减选择；框选可同时框选图片与标记元素（标记隐藏时只框选图片）；**框选会把矩形内的素材元素与 Frame 一并选中（混合多选）**；多选图片可整体移动或批量从画板移除，仍不删除项目素材或原文件；**多选删除不弹确认，直接删除**。
- 图片移动时可与其他图片及 Frame 的边缘和中心自动吸附；多选时以整体外框参与吸附。Frame 移动或缩放时可与其他 Frame 自动吸附；**元素与 Frame 按“真实几何相交”归属**（图片/矩形/文本按包围盒，椭圆按精确椭圆-矩形相交，直线/箭头/手绘按线段-矩形相交、手绘任一段碰到即算；多个 Frame 时取包围盒重叠面积最大者）：拖动开始即锁定“与 Frame 相交或已归属”的元素集合，Frame 移动时该集合同步位移（Illustrator 式），松手后按真实几何补记归属；删除 Frame 时其中图片的画板布局被移除（素材原文件保留）。对齐辅助线仅在操作中显示，按住 `Alt/Option` 可临时关闭吸附。
- **Frame 固定尺寸**：无自动撑大逻辑，图片可溢出 Frame 边界显示；拖图片到边界不会改变 Frame 尺寸。
- `空格 + 左键拖动`或鼠标中键拖动始终优先用于平移 Page 视图；光标位于 Frame、Frame 标题、素材实例或任意缩放控制点上时同样有效，并且不得触发选择、移动或缩放元素。
- 画板内的移动与删除操作（图片/文本/图形元素、Frame、以及多选/混合整组移动或删除）可用 `Ctrl/Command + Z` 撤销最近一次操作：移动恢复移动前的位置与 Frame 归属，删除把被删元素/Frame 重新插回（含其中的素材布局）；最多保留 50 步；输入框或文本编辑中不拦截撤销快捷键，缩放操作不进入撤销栈。
- **标记元素与图片混排**：文本/图形（手绘笔/矩形/椭圆/箭头/直线）与图片是同一类画板元素，共用同一 z 序（新元素置顶，可互相置顶/置底），不再有独立的“标记图层”；工具条含 指针 / 文本 / 手绘笔 / 矩形 / 椭圆 / 箭头 / 直线（快捷键 V/T/R/O 等），选中文本或图形工具即自动显示标记并进入绘图态（可在任意元素之上绘制），指针工具下所有元素都可选择/移动/缩放。
- **一键隐藏标记**：工具条提供“隐藏标记”开关，点击隐藏全部文本/图形元素（仅隐藏显示，不影响元素数据与编辑），再点恢复；输入搜索词不影响该开关。
- 标记元素（shape/text）支持选中、删除（Delete 键或工具条）、移动、缩放；文本双击进入编辑：**回车换行、`Ctrl/Cmd+Enter`、`Esc` 或点击空白处结束编辑**，编辑已有文本时预填现有内容（含多行），内容为空时自动移除；工具条提供**字号输入**（8～120，选中文本时调整并实时保存当前文本、未选中时作为新建文本默认字号）。标记与画板元素同一通道保存并多人同步；与 Frame 有交集的标记同样随 Frame 位移（与图片一致）。
- 文本元素支持完整文字格式（整段文字统一格式）：字号、水平对齐（左/中/右）、垂直对齐（顶/中/底）、加粗、斜体、下划线、删除线，以及**自动宽度**（短文本贴合内容、长文本在限宽内自动换行，保留手动换行）与**自动高度**（框高跟随内容）模式；**新建文本默认开启自动宽度+自动高度**；关闭任一自动尺寸时把框宽/框高写为当前内容尺寸。选中或正在编辑单个文本元素时，文字上方弹出悬浮格式面板（含字号输入与全部格式按钮，面板操作会先提交未保存的编辑内容），格式实时保存并多人同步；顶部标记工具条同样提供字号输入（未选中文本时作为新建文本默认字号）；文本编辑的 Enter 提交会忽略输入法组合确认（中文输入法按 Enter 确认候选词不会误提交或重复文字）。
- 文本/图形与图片共用同一套框选多选与整体移动：框选可同时选中图片与标记元素，拖动任一选中元素时全部选中元素（含文本）一起移动；文本编辑完成后工具自动回到指针工具，再点空白处只取消选择，不会新建文本框。
- 图片、文本、图形元素选中后均显示**八个缩放把手**：四角自由缩放（宽高同时），四边只缩放单轴（左右边改宽、上下边改高），锚定对侧；自动宽/高的文本从**当前内容尺寸**开始缩放，且**按被拖动的轴退出自动尺寸**——拖宽度边（左/右）只退出自动宽度、保持自动高度，拖高度边（上/下）只退出自动高度、保持自动宽度，拖角（宽高同时变化）才两个都退出。
- **Frame 始终在最底层**：元素 z 序不会低于 Frame，任何元素都显示在 Frame 之上。
- 画布坐标支持负数（无限画布），坐标与尺寸保持浮点精度、无最小尺寸钳制、线宽按缩放精确补偿，平移/缩放到任意区域绘制都不出现“吸附/跳动”或漂移。
- 左侧项目素材托盘以 2 列正方形缩略图展示，去掉名称/点击添加/计数，改为拖拽到画板插入（落在鼠标位置，与 Frame 有交集则归属该 Frame）；托盘顶部提供搜索框（名称+标签模糊匹配）；**标签区默认收起，提供“标签”展开/收起按钮**，展开后以 chip 展示全部标签（点击 chip 筛选、再点取消，chip 可拖到画板在落点附近以网格批量插入该标签下的全部项目素材）；**输入搜索词时标签自动展开**，标签与图片都按搜索词过滤展示。
- 拖拽素材/标签到画板时显示跟随鼠标的轻提示文案，不弹出全屏上传遮罩（全屏“松开即可添加图片”遮罩仅对真实文件上传触发）。
- Page、Frame、素材实例与标记元素布局均保存在服务端；Frame 的名称、位置、尺寸跨设备一致，本机缓存仅作离线兜底。
- 自由画板与维度预览使用相同的窗口适配规则：占满顶栏之下的全部剩余浏览器空间，不得撑高页面或超出可视区。
- 自由画板第一行工具栏最右侧提供与维度预览一致的“专注显示视图”按钮（`Maximize2`/`Minimize2` 图标切换）：点击后画板以页面内部固定层覆盖整个浏览器可视区（不调用浏览器 Fullscreen），再次点击退出；专注期间锁定页面滚动，素材详情抽屉、弹窗与 toast 等浮动 UI 仍显示在其上方；专注模式下按 `Esc` 退出（素材详情抽屉或弹窗打开时 `Esc` 优先关闭浮层）。
- 布局本地优先持久化：编辑立即生效、后台批量提交；网络异常时继续可编辑并在恢复后自动补齐；进入页面或从其它标签切回时拉取最新，停留期间低频兜底刷新（不做秒级实时推送）。
- 不同元素的并发修改互不覆盖；同一元素冲突采用最后写入；本地未同步的改动不会被服务器快照覆盖。

### 3.6 存储与删除

- 结构化业务数据和 Metadata 以数据库为唯一来源；素材文件存放在本地媒体目录，原图与缩略图分开保存；视频原始文件与转码产物共用同一存储位置，转码成功后以产物覆盖原文件。
- 替换素材图片时必须先完整写入新的素材文件，再切换素材记录；写入或记录更新失败时继续保留旧文件，切换成功后才清理旧媒体文件。
- 软删除和恢复只修改删除标记，不移动文件。
- 只有彻底删除素材时才删除对应的磁盘文件。
- 回收站页面入口位于左侧导航最底部，列出全部软删除素材（含删除时间与引用项目数），支持恢复和永久删除；支持卡片多选、全选（按当前筛选结果）以及批量恢复、批量永久删除；恢复后素材自动回到原项目；永久删除会同时移除所有项目引用与画板内容并删除文件，执行后立即从回收站隐藏并显示 5 秒撤销条，5 秒后提交服务端删除。
- 素材详情不再提供永久删除入口；删除素材统一先软删除进入回收站，恢复或永久删除只在回收站内进行。
- 在全部素材页删除素材时立即软删除并移出列表，只提示「已移入回收站」，不显示 5 秒撤销条；需要反悔时到回收站恢复。永久删除只在回收站内进行，采用 5 秒撤销条。
- 可恢复的删除（素材软删除、从项目移除素材、从 Page 移除素材）不弹确认框；彻底删除（维度、回收站永久删除、项目、Page、标签）不弹确认框，改为立即生效 + 5 秒撤销条；清理未使用标签直接执行，不显示撤销。

### 3.7 AI 自动打标签

- 只对图片素材生效：视频素材不提供 AI 打标入口（上传窗口与素材详情页对视频隐藏 AI 按钮），服务端对视频类型直接拒绝。
- 素材详情页（全局库与项目两处抽屉共用）的“全局标签”输入行右侧提供“AI 打标”按钮（位于手动添加标签的加号旁），一次只对当前打开的素材打标。
- 上传窗口的“全局标签”输入框旁同样提供“AI 打标”按钮：对选中的待上传图片调用同一打标链路返回建议标签（复用/新建数量以 toast 提示），建议标签合并进标签输入框供编辑确认后随上传提交；上传前打标不提前落库、不改动标签字典与使用次数。
- AI 服务不内置：通过 OpenAI 兼容接口调用。“标签管理”面板内的“AI 服务配置”入口可填写接口地址、API key 与模型名并提交到服务端保存；key 只存服务端、页面只显示尾号掩码，配置页提供“测试连接”与“查看可用模型”按钮。环境变量优先于页面配置生效；配置文件默认与数据库同目录，可用 `AI_CONFIG_PATH` 覆盖，生产环境另可写入 `/etc/artdatabase/env`。未配置时触发按钮返回明确错误提示。
- 服务端同步执行，前端只有“等待中 / 成功 / 失败”三种状态（无进度轮询）：等待中按钮 loading，成功以 toast 提示复用/新建数量，失败 toast 展示原因并可重试。
- 打标质量规则（实现见 AOCI 中 `app/server/ai.js` 条目）：
  1. 优先复用现有标签字典，只有确实没有合适标签时才新建，且新建数量尽量少；
  2. 只输出中文标签，单次最多 30 个；
  3. 对语义相近但未精确命中的标签先做一次轻量裁决，优先复用，避免产生近义变体；
  4. 最终结果与现有人工标签合并去重，总上限 50 个，人工标签优先保留，AI 新标签追加在后，来源记为 AI。
- 只打标签，不生成描述等其他字段。

### 3.8 标签字典与标签管理

- 标签以独立字典存储，素材与标签多对多关联，并记录每次建立关联的来源；对外继续保持素材标签为字符串数组的契约。
- 来源记录：标签的来源表示首次创建方式（人工/AI），关联的来源表示每次建立关联的方式；人工编辑素材时保留未改动关联的来源。
- 单素材标签总数上限 50 个（人工与 AI 统一，编辑与上传同样生效）。
- 全部素材页顶部搜索栏左侧提供“标签管理”入口，面板内为搜索框 + 按使用次数排序的标签列表，每行显示标签名、使用次数与来源；面板高度固定为视口内的最大高度，列表撑满剩余空间并内部滚动。
- 支持操作：重命名（新名与已有标签重名时等价于合并）；合并（点任意行的合并图标进入合并模式，该标签一次点击即进入备选；合并模式下整行可点击以增删备选标签，标签列表右侧展示“包含所选标签的素材”画框（占三分之二宽度，图片两列排列、纵向滚动，卡片显示素材名称与所选中的标签），底部显示“最终保留的标签/删除的标签”两行结果与已选标签组件，点击组件中的任意标签指定为最终保留、再点其他标签即替换，未选择保留标签时显示提示文案，确认后其余选中标签并入保留标签）；删除（从所有素材移除该标签并从字典删除，立即从列表隐藏并显示 5 秒撤销条，5 秒后提交服务端删除）；清理未使用（一键删除零引用标签，直接执行、不弹确认）。
- 标签全局共享：重命名/合并/删除影响所有项目引用；详情编辑器联想词只列出使用数大于 0 的标签；零引用标签保留在字典中可被 AI 复用，直到被“清理未使用”删除。
- 项目素材库工具栏同样提供“标签管理”入口：只展示该项目使用的标签，仅支持重命名与删除（无合并、清理未使用与 AI 服务配置），操作同样全局生效。

### 3.9 账号系统

- 两级角色：**管理员**与**成员**。管理员专属：成员管理（创建/停用/重置密码/删除/改角色）与 AI 服务配置；标签字典维护与彻底删除素材等日常操作全员可用。
- 登录页提供**游客浏览**：无需账号，可查看项目列表、项目工作区（维度预览、自由画板、素材库）、全局素材库与素材详情；游客身份标注为「游客（只读）」。服务端对所有非 GET 接口返回 403（退出登录除外），界面同时隐藏全部编辑入口：上传、收藏、Metadata/标签编辑、维度与 Page 增删改、坐标拖动、画板工具与拖拽、项目与成员管理、标签管理、回收站与删除。游客退出会同时清除游客 cookie。
- 游客登录仅在已完成管理员初始化后可用（无用户时返回 409）；游客 cookie 与真实会话互不影响，真实登录会清除游客 cookie，退出登录会同时清除两者。
- 不提供公开注册。首次启动（数据库无任何用户）访问时进入引导页创建管理员；之后仅管理员可增删成员，初始化完成后再次调用初始化接口返回 409。
- 存量数据整体归属首个管理员：首次设置成功后，所有无上传者的既有素材自动挂到该管理员名下，不做逐条追溯。
- 登录标识为用户名（字母、数字、点、下划线、连字符，2-50 位，大小写不敏感唯一）+ 可选中文显示名；密码最少 8 位，无自助找回，管理员可重置成员密码。
- 会话使用 HttpOnly Cookie，会话记录持久保存，重启服务不丢登录；勾选“记住我”时有效期 30 天，未勾选时 24 小时过期且关闭浏览器即失效。
- 除健康检查、登录状态、公告读取、首次初始化和管理员登录外，全部接口（含媒体图片）都必须登录；未登录返回 401，前端未登录跳转登录页，登录过期自动回到登录页。
- 停用成员立即踢下线（其全部会话失效）且不能再次登录；删除成员保留其上传的素材，上传者标记为「已删除用户」快照。
- 登录审计：登录成功与失败均记录（用户名、IP、User-Agent、结果、时间），仅管理员可通过“成员管理 → 登录记录”查看最近 100 条。
- 素材记录上传者：上传时写入上传者，素材详情展示上传者；成员改显示名不影响其历史素材的快照。
- 成员可自助修改自己的显示名与密码（改密码需验证当前密码，成功后其他会话失效），并在顶部用户菜单退出登录。
- 所有密码/密钥输入框（登录、初始化、账号设置、成员管理创建成员、AI 服务配置 API Key）均带“显示/隐藏”小眼睛，可点击切换明文查看自己输入的内容，点击不抢占输入焦点、不触发表单提交。
- 前端角色展示：管理员可见“成员管理”入口，成员隐藏“AI 服务配置”入口（服务端同时校验，越权返回 403）。
- **登录页公告与全局公告是两份独立设置**：登录页公告只在未登录的登录页展示；全局公告只在登录后的导航栏下方展示。两者各自保存内容与启用开关，编辑或关闭其中一份不影响另一份，不共用同一段文字。仅管理员可编辑（顶部用户菜单 →「登录页公告」/「全局公告」），多行纯文本、单份上限 2000 字，关闭后该位置不显示但内容保留；公告公开可读，写入仅管理员。站内全局公告条可由用户关闭，关闭标记按公告版本存在浏览器本地存储中，之后不再显示；管理员修改内容或重新保存后视为新版本，会再次显示。任何角色都可在顶部用户菜单 →「当前公告」查看站内全局公告（管理员打开编辑面板，成员/游客打开只读面板）；登录页公告不是站内公告的一部分，登录后只能在「登录页公告」面板中查看与编辑。
- **插件令牌**：任何登录用户可在顶部用户菜单 →「插件令牌」（独立面板，与账号设置分离）生成/吊销自己的令牌（可填备注；列表展示创建时间与最后使用时间）；令牌明文只在生成时返回一次，服务端只保存不可逆摘要；外部客户端（如 Chrome 扩展）以 Bearer 令牌调用接口，与浏览器登录等效（身份为该令牌所属用户，上传等操作归属本人）；令牌无过期时间、只能吊销；伪造/已吊销令牌或用户被停用/删除返回 401。扩展的下载入口与使用说明（支持浏览器等）也一并放在该面板。

### 3.10 浏览器采集扩展（Chrome「右键保存到素材库」）

- 独立的 Chrome 扩展（同时支持 Edge/Brave/Vivaldi 等 Chromium 内核浏览器，需开启开发者模式并以解压方式加载），配套服务端插件令牌（§3.9）使用；服务器地址与令牌在扩展设置页配置（单服务器，默认 `http://localhost:3000`），未配置时提示去设置（toast 内「去设置」可直达设置页）。
- 入口：任意网页的图片、视频或它们所在的容器上右键 →「保存到素材库」（统一菜单项，自动识别图片/视频）。**明确不做**：拖拽采集（与 Eagle 桌面端冲突）、悬停保存按钮、框选区域截图、保存页面全部素材、多服务器、系统通知、商店上架。
- Instagram 兼容：在 `instagram.com` 注入一条样式取消图片上方的透明覆盖层，使右键能命中图片；视频（帖子/Reel）通过 Instagram 媒体接口解析 `video_versions` 直链后下载（需要浏览器已登录 Instagram，接口变化或未登录时提示失败）。在主页采集时，来源链接优先使用素材所属的具体帖子/Reel 地址，能够确定轮播项时带上对应页码；轮播帖只保存右键选中的当前项；无法确定该项、该项没有视频或下载失败时提示失败，不得改取其他轮播项或页面中的其他视频。
- 采集流程：后台下载素材（绕过页面 CORS；`http(s):`、`data:`、`blob:` 均可，blob: 由内容脚本代为获取）→ 校验格式与大小（图片 JPEG/PNG/WebP/GIF/SVG/TIFF/HEIC/HEIF ≤50MB；视频 mp4/webm/mov/mkv/avi/mpeg/3gp ≤200MB）→ 全局查重 → 重复则页面内 toast「已存在，未保存」直接跳过（不弹面板）；不重复则在当前页面注入浮动确认面板。
- 确认面板字段：预览（图片显示缩略预览；视频显示占位 + 大小 + “上传后自动转码”）+ **项目**（必选，默认记住上次使用的项目，加载失败可点重试）+ **名称**（默认取 alt → URL 文件名 → “未命名-时间戳”兜底，可编辑）+ **标签**（逗号分隔、联想自标签字典、上限 50）+ **来源链接**（默认当前页面 URL；Instagram 优先为素材所属具体帖子/Reel URL，轮播可带页码；可编辑）+ **备注** + **「AI 打标」按钮**（仅图片显示，建议标签合并进标签框，不提前落库；视频隐藏）。
- 提交：使用与网页端相同的上传接口；成功 toast「已保存到项目X」并关闭面板；视频上传后服务端异步转码；上传竞态 409 也按「已存在，未保存」处理；401 提示去设置页更新令牌。
- 数据流：素材只下载一次并临时保留在扩展后台内存中（关面板或上传后释放）；不通过消息通道传递大文件，图片预览随面板下发、视频不传大字节；内容脚本消息带超时兜底，不永久挂起。
- 网络分工：对 artDatabase 的请求统一在扩展后台发起并携带 Bearer 令牌；内容脚本只负责 UI、右键目标解析、blob 素材代取，以及 Instagram 视频直链解析（使用页面登录态）。

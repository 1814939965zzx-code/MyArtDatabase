# artDatabase 当前需求

> 本文档是当前产品规则的唯一入口。历史版本仅供追溯，不得覆盖本文档。
> 最后整理：2026-08-17

## 1. 产品范围

artDatabase 是面向团队的图片素材库。素材存放在全局素材库中，项目通过引用组织素材；全局标签用于跨项目检索，项目维度用于项目内排序和对比，自由画板用于空间化整理素材。

MVP 约束：

- 只支持图片，不支持视频和音频。
- 通过局域网提供服务，不提供用户注册、登录和权限分级。
- 不支持批量上传，不要求自动备份。
- 不提供图片裁剪、调色、加字等在线编辑。
- 不记录 Metadata 历史版本。

## 2. 核心模型

- **全局素材**：一份图片文件、一条素材主记录和一份唯一 Metadata，可同时被多个项目引用。
- **项目**：一级分类，只保存素材引用；删除项目不能删除全局素材。
- **全局标签**：素材级自由输入标签，修改后同步影响所有项目引用。
- **项目维度**：项目级坐标，由左右端名称和连续数值组成。
- **自由画板**：项目下的持久化画布，一个项目可以有多张画板。

Metadata 字段：

| 字段 | 来源 | 要求 |
| --- | --- | --- |
| 素材名称 | 用户可编辑 | 必填；上传时默认为去扩展名文件名 |
| 全局标签、描述、备注、来源链接 | 用户可编辑 | 可空 |
| 上传时间、原始文件名、文件大小、图片尺寸、格式 | 系统生成 | 只读 |
| 时长 | 系统预留 | 图片为空 |

主要数据表：`projects`、`project_dimensions`、`assets`、`project_assets`、`asset_dimension_values`、`canvases`、`canvas_items`。

## 3. 当前有效行为

### 3.1 项目与素材

- 支持创建、重命名和删除项目。
- 支持全局素材库和项目素材的网格/列表浏览。
- 支持按素材名称、原始文件名、标签和引用项目搜索。
- 全部素材页展示全部全局标签；单标签筛选可切换，并与关键词按 AND 组合。
- 项目中的素材是全局素材引用；“从项目移除”只删除引用。
- 素材详情中不裁切原图，图片在可用宽高内等比例完整展示。
- 全局详情和项目详情均可编辑名称、全局标签、描述、来源链接和备注；项目详情额外编辑该项目的全部维度值。
- 关闭按钮、遮罩和 `Esc` 都必须先自动保存已修改的 Metadata；校验或保存失败时保持详情打开。
- 详情打开时锁定背景页面滚动，右侧详情面板可以独立滚动。

### 3.2 上传

- 支持文件选择、拖拽和剪贴板粘贴。
- 支持 JPEG、PNG、WebP，单文件上限 50 MB，一次只上传一张。
- 上传前使用 SHA-256 检测完全重复文件；用户可以引用已有素材或保留为新素材。
- 正式提交前编辑全局标签和当前项目的全部维度值。
- 新素材自动加入当前项目；取消上传不得创建素材记录。
- 服务端生成最长边不超过 900 px 的 WebP 缩略图。

### 3.3 项目维度

- 一个项目可以创建任意数量的维度。
- 一次预览最多选择三个维度：一个维度显示一维轴，两个显示二维平面，三个显示三维空间。
- 上传和编辑素材时必须显示项目的全部维度，不受预览上限影响。
- 界面值范围为 `0.00～10.00`，保留两位小数；数据库以整数 `0～1000` 存储。
- 素材加入项目或项目新增维度时，默认值为 `5.00`。
- 同一素材在同一项目、同一维度下只能有一个值。
- 删除已有项目维度或全局标签时，先显示 5 秒倒计时；倒计时结束后才写入数据库，期间可以撤销。

### 3.4 维度预览

- 三轴从中心向正负两端延伸并在中心相交；轴端显示维度左右端名称，不显示承载边框。
- 图片始终面向摄像机，不随视角旋转倾斜。
- 空白区域左键拖动旋转视角；指针位于图片上时使用空格 + 左键拖动视角。
- 普通左键拖动图片修改前两个维度；`Shift` + 左键拖动修改第三维度；松开后写入服务端。
- 图片拖动按当前视角反投影，并保留按下点与图片中心的偏移，起步不得跳变。
- 水平旋转支持完整 `360°` 循环，方向与鼠标移动一致；俯仰范围为 `0°～180°`，到边界停止。
- XY 平面是透明正方形网格，按 `0～10` 每 `1` 单位一格；网格只作视觉参照，不参与指针命中。
- Hover、单击和拖动共用投影后的屏幕矩形命中；Hover 图片在原坐标放大到 `1.65` 倍。
- 坐标系各轴和维度坐标间距使用基准尺寸的 2 倍，X/Y/Z 保持相同放大比例。
- Hover 放大区域与前方图片重叠时，这些遮挡图片以与 Hover 放大相同的 `.18s` 过渡时长淡出；1D 展示按同深度下的实际绘制顺序判定前方遮挡。Hover 结束或开始拖动、转动、缩放时恢复，不修改维度值。
- 预览最小高度为 640 px，滚轮缩放范围为 `35%～280%`。
- 左侧菜单可以隐藏；专注模式在页面内部实现，不调用浏览器 Fullscreen。

### 3.5 自由画板

- 一个项目可以创建、切换、重命名和删除多张画板。
- 支持素材元素拖动、缩放、旋转、置顶、置底和移除。
- 布局持久化，并通过短轮询支持局域网多人同步。
- 不同元素的并发修改互不覆盖；同一元素冲突采用最后写入。

### 3.6 存储与删除

- SQLite 是结构化业务数据和 Metadata 的唯一来源。
- 原图存放在 `media/blobs/`，缩略图存放在 `media/thumbs/`。
- 软删除和恢复只修改 `deleted_at`。
- 只有彻底删除素材时才能删除对应的原图和缩略图文件。

## 5. 技术运行边界

- 单个原生 Node.js 进程同时提供前端、`/api/*`、SQLite 和图片存储。
- 默认开发数据位于 `app/data/app.db` 和 `app/data/media/`。
- 环境变量：`PORT`（默认 `3000`）、`DB_PATH`、`STORE_ROOT`。
- Node.js 要求 `>=23.4.0`。
- 启动、验证和部署方式分别以根目录 `README.md`、`AGENTS.md` 和 `BUILD.md` 为准。

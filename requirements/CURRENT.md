# artDatabase 当前需求

> 本文档是当前产品规则的唯一入口。历史版本仅供追溯，不得覆盖本文档。
> 最后整理：2026-08-25

## 1. 产品范围

artDatabase 是面向团队的图片素材库。素材存放在全局素材库中，项目通过引用组织素材；全局标签用于跨项目检索，项目维度用于项目内排序和对比，自由画板用于空间化整理素材。

MVP 约束：

- 只支持图片，不支持视频和音频。
- 通过局域网提供服务，**已启用账号系统**（见 §3.9）：不提供公开注册，首次启动引导创建管理员，之后仅管理员可增删成员。
- 不支持批量上传，不要求自动备份。
- 不提供图片裁剪、调色、加字等在线编辑。
- 不记录 Metadata 历史版本。

## 2. 核心模型

- **全局素材**：一份图片文件、一条素材主记录和一份唯一 Metadata，可同时被多个项目引用。
- **项目**：一级分类，只保存素材引用；删除项目不能删除全局素材。
- **全局标签**：素材级标签，人工输入或 AI 生成；存于独立标签字典（`tags`/`asset_tags`），同一标签在所有素材间复用，修改后同步影响所有项目引用。
- **项目维度**：项目级坐标，由左右端名称和连续数值组成。
- **自由画板**：项目下的无限画布；Frame 为可选容器，素材以实例组织，另含一个覆盖全部图层的可开关草稿标记图层（文本与描边图形）。

Metadata 字段：

| 字段 | 来源 | 要求 |
| --- | --- | --- |
| 素材名称 | 用户可编辑 | 必填；上传时默认为去扩展名文件名 |
| 全局标签 | 用户可编辑；AI 可自动生成 | 可空；单素材上限 50 个 |
| 描述、备注、来源链接 | 用户可编辑 | 可空 |
| 上传时间、原始文件名、文件大小、图片尺寸、格式 | 系统生成 | 只读 |
| 时长 | 系统预留 | 图片为空 |

主要数据表：`projects`、`project_dimensions`、`assets`、`project_assets`、`asset_dimension_values`、`canvases`、`canvas_items`、`tags`、`asset_tags`、`users`、`sessions`、`login_logs`。

## 3. 当前有效行为

### 3.1 项目与素材

- 支持创建、重命名和删除项目。
- 支持全局素材库和项目素材的网格/列表浏览。
- 支持按素材名称、原始文件名、标签和引用项目搜索。
- 全部素材页展示全部全局标签；标签筛选为多选，选中多个标签时按 OR 组合，并与关键词按 AND 组合。
- 项目素材页新增标签筛选模块，默认展示该项目素材包含的全部标签，筛选同样为多选并按 OR 组合。
- 全部素材页与项目素材页共用同一标签筛选模块：默认展示 2 行、超出可展开收起，已选中的标签排最前；全部素材页的视图切换独立一行位于标签卡片下方靠右，标签管理入口位于顶部搜索栏左侧。
- 项目视图页签顺序为“维度预览 → 自由画板 → 素材库”，进入项目后默认打开维度预览。
- 项目中的素材是全局素材引用；“从项目移除”只删除引用。
- 素材详情中不裁切原图，图片在可用宽高内等比例完整展示。
- 全局详情和项目详情均可编辑名称、全局标签、描述、来源链接和备注；所有文本输入必须支持普通空格和中文输入法组合输入。
- 来源链接默认以只读链接展示，点击后在新标签页打开；无链接时使用“增加”进入输入状态，已有链接时使用“编辑”修改，跳转只允许 `http://` 和 `https://`。
- 已有素材可以通过文件选择或在详情打开时粘贴剪贴板图片进行替换；确认前展示新旧图片对比，并可用 `Ctrl/Command + Z` 撤销待替换图片。替换只更新图片文件及其系统生成信息，素材 ID、Metadata、项目引用、维度值、画板元素和创建时间必须保持不变。
- 标签以左对齐、横向排列并自动换行的 Badge 展示；删除图标位于 Badge 左侧。新增标签使用单一输入框，输入时模糊匹配已有全局标签，也允许创建新标签。输入匹配到已有标签时，需用方向键上下选中建议项后按回车或空格插入；未选中时回车按输入原文添加（若原文与某待删除标签一致则撤销其删除状态）。
- 标签删除无需倒计时：点击删除图标（无论该标签是素材原有还是本次新添加）后标签原地变为删除线样式（红色），删除图标切换为撤销图标；再次点击可撤销。关闭详情时统一结算：保存的标签集合自动排除所有待删除标签，一次提交完成新增与删除。
- 详情中不再显示“保存素材信息”按钮；关闭按钮、遮罩和 `Esc` 都必须先自动保存已修改的 Metadata，校验或保存失败时保持详情打开。
- 详情打开时锁定背景页面滚动，右侧详情面板可以独立滚动。

### 3.2 上传

- 支持文件选择、拖拽和剪贴板粘贴。
- 支持 JPEG、PNG、WebP，单文件上限 50 MB，一次只上传一张。
- 上传前使用 SHA-256 检测完全重复文件；用户可以引用已有素材或保留为新素材。
- 正式提交前编辑全局标签和当前项目的全部维度值。
- 上传窗口的维度值按 `-100～100` 展示，新素材默认位于中点 `0`。
- 新素材自动加入当前项目；取消上传不得创建素材记录。
- 服务端生成最长边不超过 900 px 的 WebP 缩略图。

### 3.3 项目维度

- 一个项目可以创建任意数量的维度。
- 一次预览最多选择三个维度：一个维度显示一维轴，两个显示二维平面，三个显示三维空间。
- 上传和编辑素材时必须显示项目的全部维度，不受预览上限影响。
- 数据库与 API 继续以整数 `0～1000` 存储维度值；界面统一按 `(storedValue - 500) / 5` 映射为 `-100～100`。
- 素材加入项目或项目新增维度时，默认位于中点（界面 `0`，内部存储 `500`）。
- 项目素材详情外层的维度 Slider 始终可以直接调整当前素材的位置，松开或失焦时保存。
- 每条维度右侧各有一个无文案的编辑图标按钮；点击后只编辑该维度的左右端名称，不影响外层 Slider。浮窗提供“取消”和“应用修改”，名称保存后在当前项目的素材详情、上传窗口和维度预览中全局生效。
- 维度两端名称必填、各不超过 24 个字符，且去除首尾空格后不能相同；校验或应用失败时保持浮窗打开。
- 维度 Slider 步进为 1 个界面单位（对应 5 个存储单位），强调色填充从轨道中点 `0` 向当前值延伸，不从最左端起算。
- 同一素材在同一项目、同一维度下只能有一个值。
- 删除已有项目维度时，先显示 5 秒倒计时；倒计时结束后才写入数据库，期间可以撤销。

### 3.4 维度预览

- 三轴从中心向正负两端延伸并在中心相交，渲染为有厚度的 1px 细线（任意角度均可见）；轴端不绘制箭头，只显示维度左右端名称且不显示承载边框；坐标轴不显示数值刻度。
- 坐标轴的角落展示各维度端点名称的组合：2D 平面四角显示两词组合；3D 空间的 XY、XZ、YZ 三个平面四角各显示两词组合，八个顶点显示三词组合。
- 图片始终面向摄像机，不随视角旋转倾斜。
- 3D 预览中无论指针位于空白区域还是图片上，左键拖动都只旋转视角；点击图片仍打开素材详情。1D、2D、3D 预览均可按住空格 + 左键拖动平移整个视图。3D 模式下图片不可拖动，hover 图片时保持默认光标，不切换为抓取光标。
- 3D 预览右上角提供“隔离当前象限”控件（按钮与说明文字上下排列，说明文字不带边框）：点击时比较八个空间象限中心的投影深度，锁定离当前摄像机最近的象限，隐藏其他象限的图片、坐标轴和文字描述，并改为绕该象限中心旋转。隔离期间不随后续旋转动态切换象限；按钮下方按三个已选维度的顺序显示当前象限对应的三个端点名称，如“古典、成熟、敏捷”，未隔离时则显示即将进入的象限名称；再次点击退出并恢复全部图片和全局原点。
- 位于任一维度中点 `0`（存储值 `500`）的图片视为位于当前隔离象限的边界上，其他维度符合时保留显示。
- 只有 1D 和 2D 预览允许拖动图片修改维度值，松开后写入服务端；3D 预览不允许通过拖动图片修改任何维度坐标。
- 素材图片默认宽度统一为 90px（单张、堆、展开平面卡片一致；堆拖动接近时放大到 132px 提示），宽高按原比例规则（1:1 / 3:4 / 4:3）确定；图片以最短边适配方式完整显示（`contain`），不裁切、不拉伸；图片无阴影、背景透明，不显示垫底色块。
- 预览工具栏提供“图片缩放系数”滑块（50%～200%，100% 为默认 90px）：作为所有预览图片（单张、堆、展开平面卡片）统一的缩放系数，叠加在默认尺寸之上（含堆拖动提示的 132px 放大），与场景缩放（间距密度）相互独立；设置写入 localStorage 记住，再次打开预览保持上次数值。
- hover 或拖动图片时，图片正上方显示坐标气泡：气泡固定大小（不随图片 hover 放大），文字 14px，跟随图片朝向摄像机；内容为素材所在侧端点名称与数值绝对值（如“抽象 30”“具象 30”），2D/3D 按选中维度依次排列。坐标轴两端始终只显示端点名称，不显示任何数值。
- 3D 预览工具栏不提供俯仰/旋转滑条，视角完全由鼠标拖拽控制。
- 图片拖动按当前视角反投影，并保留按下点与图片中心的偏移，起步不得跳变。
- 水平旋转支持完整 `360°` 循环，方向与鼠标移动一致；俯仰范围为 `0°～180°`，到边界停止。
- XY 平面是透明正方形网格，只作视觉参照，不参与指针命中（不显示数值刻度）。
- Hover、单击和拖动共用投影后的屏幕矩形命中，命中区域与图片实际视觉大小一致（Hover 放大后按放大区域判定）；Hover 图片在原坐标放大到 `2.475` 倍（放大后的整体大小与原 4.95 倍时一致）。
- 坐标系各轴和维度坐标间距使用基准尺寸的 2 倍，X/Y/Z 保持相同放大比例。
- Hover 放大和遮挡隐藏在 1D、2D、3D 使用同一套规则：放大区域与前方图片/堆重叠时，遮挡对象以与 Hover 放大相同的 `.18s` 过渡时长淡出；先按投影深度判定前后，深度相同时按实际绘制顺序判定。单张 hover 会淡出前方的堆与图片；堆 hover（展开平面）同样会淡出平面区域内、投影深度靠前的堆与图片。Hover 结束或开始拖动、转动、缩放时恢复，不修改维度值。
- hover 单张图片或堆且存在前后遮挡的图片时，可按 `Tab` 在“当前图 + 所有与放大区域屏幕重叠的图片（单张与堆）”之间循环切换焦点（按投影深度前后排序，含前后方向），`Shift+Tab` 反向切换；切到单张时等同 hover（放大 2.475 倍并淡出它自己的遮挡者，点击即打开该图详情），切到堆时展开该堆的悬浮平面。循环列表以鼠标当前 hover 的图片或堆为锚点；鼠标移出即清空、无记忆。鼠标位于预览画布内时，按 `Tab` 不执行浏览器默认的焦点切换（不跳转到侧栏/工具栏等元素）。
- 维度预览场景内文字（轴端点名称、角落组合、坐标气泡等）在 1D、2D、3D 下均不可被鼠标选中。
- 维度预览占满顶部栏和项目视图标签之下的全部剩余浏览器空间，不得撑高页面或超出可视区。
- 坐标原点默认投影在右侧预览视口的水平、垂直中心；用户平移后可偏离中心，重置视角时恢复居中。坐标系大于视口时默认必须对称溢出，不得偏向右下方。
- 预览高度跟随浏览器剩余空间，场景滚轮缩放范围为 `35%～280%`。
- 左侧菜单可以隐藏；专注模式在页面内部实现，不调用浏览器 Fullscreen。
- 景深：以原点（0,0,0，即 worldZ=0）为焦点，深度在其之后（更远离摄像机）的图片与堆按距离逐渐模糊（每 150 深度单位 1px，最多 5px，0.5px 步进）；展开平面内的卡片不参与景深。
- 素材重叠统一采用“随坐标聚簇堆叠”：1D、2D、3D 预览均按维度坐标空间距离聚簇，合并半径为坐标空间距离、按缩放档位取值，且 1D/2D/3D 各自独立（低倍档当前：1D 各档 40、2D 为 80/70/50/40、3D 为 120/110/100/70；125% 及以上档按 70÷档位 递减：56/44/34/25），缩放越精细；旋转视角不改变分组，缩放仅在跨档时重组，素材坐标变化、维度选择或象限隔离切换同样触发重组；聚簇只统计当前可见素材（隔离象限内），正在拖动的单张不参与。
- 一个堆收起为“一摞卡片”：取屏幕上最靠前的 2～3 张缩略图错位叠放，右上角显示数量徽标，位置取成员质心；不足 2 张不成堆，按单张渲染。
- hover 堆时生成一个与堆完全重合的悬浮 2D 平面（原堆整体隐藏、平面无底色），成员在平面内按矩阵展开（列数 = ⌈√成员数⌉，如 1→1×1、2→1×2、3~4→2×2、5~9→3 列、10~16→4 列，以此类推；展示全部成员、按屏幕最靠前排序、卡片 90px 方形等间距）；展开时卡片从中心位移到各自位置（约 0.18s），退出 hover 时卡片先向中心收拢（约 0.16s）再消失；鼠标移出平面立即触发收起，滚轮缩放、旋转、平移场景时同样立即收起。
- 平面交互与场景完全独立：指针在平面上时，场景不旋转、单张不放大、不触发遮挡淡出；平面内 hover 卡片放大 1.86 倍（原 3.71 的一半）且不隐藏任何图片。
- 1D/2D 拖动图片接近某个堆时，即将进入的堆放大并高亮，提示松手后并入该堆。
- 1D/2D 可在平面内直接拖动卡片修改选中维度值（水平移动改第一维、垂直移动改第二维），3D 卡片只可点击打开详情；堆本身不可拖动、点击堆无动作。
- 未成堆的单张保留 hover 2.475 倍放大（整体放大后大小与原一致）与前方遮挡淡出（遮挡物含堆）；堆的合并/解散即时切换，不使用过渡动画。
- 开发构建在预览工具栏提供“调试”开关：开启后每个堆的聚簇范围以 50% 透明红色绘制在场景内（1D/2D 为圆，3D 为由三个正交圆盘构成的球体；半径即固定聚簇半径）；该开关与绘制逻辑仅存在于开发构建，生产构建完全剔除。

### 3.5 自由画板

- 自由画板采用无限画布，Frame 是**可选容器**：图片既可直接放在画布上，也可拖入某个 Frame 归属该 Frame；`canvas_items.parent_frame_id` 记录所属 Frame（可空）。
- 新建 Page 默认是一块**空白无限画布**（不再自动生成 `1920 × 1080` 默认 Frame），可手动创建 Frame；一个项目可创建、切换、双击重命名和删除多个 Page。
- 一个 Page 可有多个 Frame；Frame 可双击重命名，选中后可移动和从八个方向自由缩放，标题缩小时保持可读；右键可删除 Frame，含素材实例时必须确认（删除 Frame 同时移除其中图片的画板布局，不删除项目素材或原文件）。
- 同一素材可在同一 Page 内重复放置，每次放置拥有独立元素 ID 和布局。
- 从左侧托盘拖入图片时按素材原图宽高比插入（缺失尺寸退回 3:4）；图片缩放不设最大/最小限制。
- 图片元素交互简化：不显示名称 caption，无旋转操作；右下角缩放把手在 **hover 或选中**时才显示；选中工具条保留置顶/置底与删除。
- 素材元素支持拖动、缩放、置顶、置底和移除；右键删除图片只移除当前画板实例。
- 在 Page 空白区域拖动可框选多张图片，`Shift` 可增减选择；框选可同时框选图片与标记元素（标记隐藏时只框选图片）；多选图片可整体移动或批量从画板移除，仍不删除项目素材或原文件；**多选删除不弹确认，直接删除**。
- 图片移动时可与其他图片及 Frame 的边缘和中心自动吸附；多选时以整体外框参与吸附。Frame 移动或缩放时可与其他 Frame 自动吸附；**元素与 Frame 按“真实几何相交”归属**（图片/矩形/文本按包围盒，椭圆按精确椭圆-矩形相交，直线/箭头/手绘按线段-矩形相交、手绘任一段碰到即算；多个 Frame 时取包围盒重叠面积最大者）：拖动开始即锁定“与 Frame 相交或已归属”的元素集合，Frame 移动时该集合同步位移（Illustrator 式），松手后按真实几何补记归属；删除 Frame 时其中图片的画板布局被移除（素材原文件保留）。对齐辅助线仅在操作中显示，按住 `Alt/Option` 可临时关闭吸附。
- **Frame 固定尺寸**：无自动撑大逻辑，图片可溢出 Frame 边界显示；拖图片到边界不会改变 Frame 尺寸。
- `空格 + 左键拖动`或鼠标中键拖动始终优先用于平移 Page 视图；光标位于 Frame、Frame 标题、素材实例或任意缩放控制点上时同样有效，并且不得触发选择、移动或缩放元素。
- **标记元素与图片混排**：文本/图形（手绘笔/矩形/椭圆/箭头/直线）与图片是同一类画板元素，共用同一 z 序（新元素置顶，可互相置顶/置底），不再有独立的“标记图层”；工具条含 指针 / 文本 / 手绘笔 / 矩形 / 椭圆 / 箭头 / 直线（快捷键 V/T/R/O 等），选中文本或图形工具即自动显示标记并进入绘图态（可在任意元素之上绘制），指针工具下所有元素都可选择/移动/缩放。
- **一键隐藏标记**：工具条提供“隐藏标记”开关，点击隐藏全部文本/图形元素（仅隐藏显示，不影响元素数据与编辑），再点恢复；输入搜索词不影响该开关。
- 标记元素（shape/text）支持选中、删除（Delete 键或工具条）、移动、缩放；文本可双击编辑内容、缩放只改变文本框展示范围（字号不变），内容为空时自动移除；工具条提供**字号输入**（8～120，选中文本时调整并实时保存当前文本、未选中时作为新建文本默认字号）；`Esc` 退出文本编辑并回退到移动工具。标记与画板元素同一通道存服务端并多人同步；与 Frame 有交集的标记同样随 Frame 位移（与图片一致）。
- **Frame 始终在最底层**：元素 z 序不会低于 Frame（置底下限为 0，DOM 先渲染 Frame 再渲染元素），任何元素都显示在 Frame 之上。
- 画布坐标支持负数（无限画布），元素 `x/y` 与尺寸全程浮点精度、无最小尺寸钳制、线宽按缩放精确补偿，平移/缩放到任意区域绘制都不出现“吸附/跳动”或漂移。
- 左侧项目素材托盘以 2 列正方形缩略图展示，去掉名称/点击添加/计数，改为拖拽到画板插入（落在鼠标位置，与 Frame 有交集则归属该 Frame）；托盘顶部提供搜索框（名称+标签模糊匹配）；**标签区默认收起，提供“标签”展开/收起按钮**，展开后以 chip 展示全部标签（点击 chip 筛选、再点取消，chip 可拖到画板在落点附近以网格批量插入该标签下的全部项目素材）；**输入搜索词时标签自动展开**，标签与图片都按搜索词过滤展示。
- 拖拽素材/标签到画板时显示跟随鼠标的轻提示文案，不弹出全屏上传遮罩（全屏“松开即可添加图片”遮罩仅对真实文件上传触发）。
- Page、Frame、素材实例与标记元素布局保存在服务端；Frame 名称、尺寸、位置当前保存在浏览器本地。
- 自由画板与维度预览使用相同的窗口适配规则：占满顶部栏和项目视图标签之下的全部剩余浏览器空间，不得撑高页面或超出可视区。
- 布局持久化，并通过短轮询支持局域网多人同步。
- 不同元素的并发修改互不覆盖；同一元素冲突采用最后写入。

### 3.6 存储与删除

- SQLite 是结构化业务数据和 Metadata 的唯一来源。
- 原图存放在 `media/blobs/`，缩略图存放在 `media/thumbs/`。
- 替换素材图片时必须先完整写入新原图和缩略图，再切换素材记录；写入或数据库更新失败时继续保留旧图片，切换成功后才清理旧媒体文件。
- 软删除和恢复只修改 `deleted_at`。
- 只有彻底删除素材时才能删除对应的原图和缩略图文件。
- 回收站页面入口位于左侧导航最底部，列出全部软删除素材（含删除时间与引用项目数），支持恢复和永久删除；支持卡片多选、全选（按当前筛选结果）以及批量恢复、批量永久删除；恢复只清除 `deleted_at`，素材自动回到原项目；永久删除会同时移除所有项目引用与画板内容并删除图片文件。
- 素材详情不再提供永久删除入口；删除素材统一先软删除进入回收站，恢复或永久删除只在回收站内进行。

### 3.7 AI 自动打标签

- 素材详情页（全局库与项目两处抽屉共用）的“全局标签”输入行右侧提供“AI 打标”按钮（位于手动添加标签的加号旁），一次只对当前打开的素材打标。
- AI 服务不内置：通过 OpenAI 兼容接口调用。“标签管理”面板内的“AI 服务配置”入口可填写接口地址、API key 与模型名并提交到服务端保存；key 只存服务端、页面只显示尾号掩码，配置页提供“测试连接”与“查看可用模型”按钮。环境变量 `AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL` 优先于页面配置生效；配置文件默认与数据库同目录（开发 `app/data/ai-config.json`，生产 `/var/lib/artdatabase/ai-config.json`），可用 `AI_CONFIG_PATH` 覆盖，生产环境另可写入 `/etc/artdatabase/env`。未配置时触发按钮返回明确错误提示。
- 服务端同步执行，前端只有“等待中 / 成功 / 失败”三种状态（无进度轮询）：等待中按钮 loading，成功以 toast 提示复用/新建数量，失败 toast 展示原因并可重试。
- 打标链路：
  1. 取原图（本地文件直接读取，远程 URL 由服务端下载），压缩到最长边 ≤1024 后以 base64 发送；
  2. 词库优先：读取标签字典，把按使用次数排序的前 200 个标签（剔除素材已用标签）与该素材已有标签一起注入第一轮提示词；要求优先原样使用词库标签、仅当词库确实没有合适标签时才允许新建（新建数量尽量少，不超过 3 个）、禁止输出词库标签的近义变体、输出前自查去重；词库为空时退回自由生成；
  3. 第一轮视觉调用：要求只输出中文标签，引导 8~15 个、最多 30 个；
  4. 对返回标签做归一（trim、大小写、全半角）后与标签字典精确匹配，命中即复用；
  5. 未命中的生成模糊候选（每标签最多 5 个、按使用次数排序）：候选来源为子串互相包含、剥离近义尾缀（感/风/色/调/型/物/图等）后相同、或短词编辑距离相近；有候选时发起第二轮轻量文本裁决，由 AI 决定复用候选或按原词新建，裁决指令优先复用候选，裁决结果必须落在候选或原词内；第二轮失败时歧义标签退化为新建，不阻塞整体打标；
  6. 最终结果与现有人工标签合并去重：总上限 50 个，人工标签在前优先保留，AI 新标签追加在后；关联来源记为 `ai`。
- 只打标签，不生成描述等其他字段。

### 3.8 标签字典与标签管理

- 标签不再以素材逗号分隔字符串为唯一存储：新增 `tags`（唯一标签字典，含来源与时间）与 `asset_tags`（素材-标签关联，含顺序与来源），原有 `assets.tags` 列随迁移删除；对外 API 的标签契约保持字符串数组不变。
- 来源记录：`tags.source` 表示标签首次创建方式（`manual`/`ai`），`asset_tags.source` 表示每次建立关联的方式；人工编辑素材时保留未改动关联的来源。
- 单素材标签总数上限 50 个（人工与 AI 统一，编辑与上传同样生效）。
- 全部素材页顶部搜索栏左侧提供“标签管理”入口，面板内为搜索框 + 按使用次数排序的标签列表，每行显示标签名、使用次数与来源；面板高度固定为视口内的最大高度，列表撑满剩余空间并内部滚动。
- 支持操作：重命名（新名与已有标签重名时等价于合并）；合并（点任意行的合并图标进入合并模式，该标签一次点击即进入备选；合并模式下整行可点击以增删备选标签，标签列表右侧展示“包含所选标签的素材”画框（占三分之二宽度，图片两列排列、纵向滚动，卡片显示素材名称与所选中的标签），底部显示“最终保留的标签/删除的标签”两行结果与已选标签组件，点击组件中的任意标签指定为最终保留、再点其他标签即替换，未选择保留标签时显示提示文案，确认后其余选中标签并入保留标签）；删除（从所有素材移除该标签并从字典删除）；清理未使用（一键删除零引用标签）。
- 标签全局共享：重命名/合并/删除影响所有项目引用；详情编辑器联想词只列出使用数大于 0 的标签；零引用标签保留在字典中可被 AI 复用，直到被“清理未使用”删除。
- 项目素材库工具栏同样提供“标签管理”入口：只展示该项目使用的标签，仅支持重命名与删除（无合并、清理未使用与 AI 服务配置），操作同样全局生效。

### 3.9 账号系统

- 两级角色：**管理员**与**成员**。管理员专属：成员管理（创建/停用/重置密码/删除/改角色）与 AI 服务配置；标签字典维护与彻底删除素材等日常操作全员可用。
- 不提供公开注册。首次启动（数据库无任何用户）访问时进入引导页创建管理员；之后仅管理员可增删成员，初始化完成后再次调用初始化接口返回 409。
- 存量数据整体归属首个管理员：首次设置成功后，所有 `created_by` 为空的既有素材自动挂到该管理员名下，不做逐条追溯。
- 登录标识为用户名（字母、数字、点、下划线、连字符，2-50 位，大小写不敏感唯一）+ 可选中文显示名；密码最少 8 位，无自助找回，管理员可重置成员密码。
- 会话使用 HttpOnly Cookie Session（`artdb_session`，SameSite=Lax），会话记录存 SQLite，重启服务不丢登录；勾选“记住我”时服务端有效期 30 天并写 Cookie Max-Age，未勾选时服务端 24 小时过期且 Cookie 为浏览器会话级（关闭浏览器失效）。
- 除 `GET /api/health`、`GET /api/auth/status`、`GET /api/announcement`、`POST /api/auth/setup`、`POST /api/auth/login` 外，全部 `/api/*`（含媒体图片 `/api/media`）必须登录；未登录返回 401，前端未登录跳转登录页，登录过期自动回到登录页。
- 停用成员立即踢下线（其全部会话删除）且不能再次登录；删除成员保留其上传的素材，上传者标记为「已删除用户」快照。
- 登录审计：登录成功与失败均记录到 `login_logs`（用户名、IP、User-Agent、结果、时间），仅管理员可通过“成员管理 → 登录记录”查看最近 100 条。
- 素材记录上传者：上传时写入 `created_by`/`created_by_name`，素材详情展示上传者；成员改显示名不影响其历史素材的快照。
- 成员可自助修改自己的显示名与密码（改密码需验证当前密码，成功后其他会话失效），并在顶部用户菜单退出登录。
- 所有密码/密钥输入框（登录、初始化、账号设置、成员管理创建成员、AI 服务配置 API Key）均带“显示/隐藏”小眼睛，可点击切换明文查看自己输入的内容，点击不抢占输入焦点、不触发表单提交。
- 前端角色展示：管理员可见“成员管理”入口，成员隐藏“AI 服务配置”入口（服务端同时校验，越权返回 403）。
- 登录页公告：公告展示在登录页（未登录即可见），仅管理员可编辑（顶部用户菜单 → “登录页公告”），多行纯文本、上限 2000 字，带启用/关闭开关（关闭后登录页不显示，内容保留）；数据存 `app_settings` 键值表，`GET /api/announcement` 公开读取、`PUT /api/announcement` 仅管理员。

## 5. 技术运行边界

- 单个原生 Node.js 进程同时提供前端、`/api/*`、SQLite 和图片存储。
- 默认开发数据位于 `app/data/app.db` 和 `app/data/media/`。
- 静态资源路径和本地媒体存储键必须限定在各自根目录内，禁止通过编码路径、`..` 或路径分隔符访问任意文件。
- 环境变量：`PORT`（默认 `3000`）、`DB_PATH`、`STORE_ROOT`；AI 打标可选配置 `AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL`（优先于页面配置）与 `AI_CONFIG_PATH`（配置文件路径，默认与数据库同目录）。
- 账号会话存 SQLite（`users`/`sessions`/`login_logs` 表），密码使用 scrypt 哈希；会话 Cookie 为 HttpOnly + SameSite=Lax。
- Node.js 要求 `>=23.4.0`。
- 启动、验证和部署方式分别以根目录 `README.md`、`AGENTS.md` 和 `BUILD.md` 为准。

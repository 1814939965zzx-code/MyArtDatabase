# AI 识图自动打标签服务调研（外部云 API 方案）

> 调研日期：2026-08-18（v2 修订）
> 范围：**仅调研外部云端 API 方案**；离线/本地模型方案暂不考虑。
> 本文档只做服务选型调研，不涉及实现方式与代码改造。
> 调研结论尚未进入产品规则（CURRENT.md 未更新）。

## 1. 结论摘要

1. **首选：阿里云百炼 `qwen-vl-plus`**（或更新的 Qwen3-VL-Plus）——中文标签强、支持结构化输出、限流充裕、批量推理（Batch）半价、国内直连，单张图约 **¥0.001～0.002**。
2. **备份与压价：智谱 GLM-4.6V-FlashX**——输入 $0.04/百万 tokens，是目前已知最便宜的视觉大模型之一；**GLM-4.6V-Flash 完全免费**，适合先做小样验证。
3. **免费额度打前站**：智谱 Flash 免费版 + 百度智能云"通用物体识别"企业 3 万次免费额度 + 腾讯云每月 1000 次免费额度，足够完成选型验证，验证期零成本。
4. **不推荐传统 CV 预置识别 API（百度/腾讯的"通用物体识别/商品识别"）作为主方案**：它们词表固定（物体/动物/菜品等），无法产出素材库最需要的**风格、色调、氛围、构图**类标签。
5. 成本量级结论：1 万张图约 **¥4～300**，10 万张约 **¥40～3000**，成本不是主要决策因素，**标签质量与中文能力才是**。

## 3. 各家详情

### 3.1 阿里云百炼：qwen-vl-plus / Qwen3-VL-Plus

- **能力**：千问视觉语言大模型，细节识别和文字识别强，支持超百万像素与任意长宽比；输入上限 129K tokens，输出上限 8192。
- **价格**（北京区，[官网](https://help.aliyun.com/zh/model-studio/qwen-vl-plus)）：输入 ¥0.8/百万 tokens，输出 ¥2/百万 tokens；**Batch File 输入 ¥0.4、输出 ¥1（半价）**，适合一次性批量补打存量素材。
- **限流**：RPM 1200、TPM 1,000,000——同类里最宽裕，适合大规模批量。
- **结构化输出**：北京区支持；不支持联网搜索和 Function Calling（打标签用不到）。
- Qwen3-VL-Plus 为新一代模型，能力更强（[QwenCloud](https://www.qwencloud.com/models/qwen3-vl-plus)），价格以百炼控制台为准。
- 单张 1024px 图按约 1000～2000 输入 tokens 估算：**约 ¥0.001～0.002/张**（输出 150 tokens 计）。

### 3.2 智谱 AI：GLM-4.6V / GLM-4.5V（[Z.ai 定价页](https://docs.z.ai/guides/overview/pricing)）

| 模型 | 输入（$/M tokens） | 输出（$/M tokens） | 说明 |
| --- | --- | --- | --- |
| GLM-4.6V | $0.30 | $0.90 | 主力视觉模型 |
| GLM-4.6V-FlashX | **$0.04** | $0.40 | 极便宜，性价比首选 |
| GLM-4.5V | $0.60 | $1.80 | 41 个榜单 SOTA（[开源实测](https://www.aixq.cc/3199.html)） |
| GLM-4.6V-Flash | 免费 | 免费 | 验证期零成本 |

- 能力：GLM-4.5V 看图理解、细粒度识别口碑好（可区分麦当劳与肯德基炸鸡这类细节）；中文能力强。
- 注意：Z.ai 为国际站（USD）；**国内站 open.bigmodel.cn 另有人民币定价与赠送额度，以国内站为准**。
- FlashX 按 1024px 图估算约 **$0.00005～0.0001/张（¥0.0004～0.0007）**。

### 3.3 火山引擎：豆包视觉大模型

- 在 2026 年中文视觉理解评测中排名第一梯队（[中文视觉大模型评测报道](https://www.163.com/dy/article/KRLUG3GK0511CPVM.html)），中文标签质量与通义、智谱同档。
- 按 token 计费、有结构化输出；具体单价以火山引擎官网为准（调研时未获取到稳定公开价目）。
- 适合团队已有火山云/字节生态账号的情况。

### 3.4 腾讯云（[视觉理解大模型计费](https://buy.cloud.tencent.com/price/imagetag)）

- **视觉理解大模型（vita）**：输入 ¥1.2/百万 token，输出 ¥3.5/百万 token，无免费额度，提供"应用场景模式"和"自定义 Prompt 模式"。
- **传统 CV 图像识别（商品识别/宠物识别等）**：免费额度 1000 次/月；后付费阶梯价，商品识别 ¥2.5/千次起（约 ¥0.0025/次），量大批发价更低。
- 传统 CV 只识别物体词表，对素材库的"风格/色调/氛围"标签贡献有限。

### 3.5 百度智能云（[图像识别产品价格](https://cloud.baidu.com/doc/IMAGERECOGNITION/s/gk3bcx9n1)）

- **通用物体和场景识别**：免费测试资源——个人认证 1 万次、企业认证 **3 万次**（一次性）；用尽后按次数包/后付费计费（约 ¥0.0025/次量级，以官网动态价格表为准）。返回"标签 + 置信度 + 中文释义"，**无需写 prompt**。
- **看图识万物**：免费 100/200 次；**图像内容理解**：免费 500/1000 次（以上为个人/企业）。
- 大模型路线另有千帆 ERNIE-VL 系列（按 token），中文能力强。
- 局限同上：词表偏物体/场景，风格与氛围类标签缺失，不适合单独作为主方案。

### 3.6 海外：Google Gemini 2.5 Flash

- 价格（[2026 比价](https://www.clawrouters.com/blog/cheapest-vision-multimodal-llm-api-2026)）：输入 $0.30/百万 tokens、输出 $2.50/百万 tokens。
- 图片 token 阶梯计费（[图片计费规则](https://theneuralbase.com/gemini-api/learn/beginner/pricing-model-per-character-and-per-image/)）：≤384px 258 tokens、≤768px 1032 tokens、≤1536px **4130 tokens**、更大 16630 tokens。1024px 图约 4130 tokens → 单张约 **$0.0012～0.0017（≈¥0.009～0.012）**。
- 中文标签质量强、速度极快、支持 response_schema 结构化输出；**国内网络直连受限**是主要障碍。

### 3.7 海外：OpenAI GPT-4o / GPT-4.1

- 图片按 512×512 瓦片计 token（170 tokens/瓦片 + 85 基础），1024×1024 图 = 4 瓦片 = **765 tokens**（[计算器](https://github.com/jamesmcroft/openai-image-token-calculator)、[视觉计费说明](https://theneuralbase.com/openai/learn/intermediate/what-vision-costs-token-pricing-for-images/)）。
- GPT-4o：输入 $2.50/百万、输出 $10/百万 → 单张约 **$0.003～0.005（≈¥0.02～0.04）**，是通义的 10 倍以上；GPT-4.1 略便宜。
- 质量公认顶尖，但**性价比和国内直连都不占优**，仅作备选。

### 3.8 Azure AI Vision / AWS Rekognition（预置标签 API）

- AWS Rekognition `DetectLabels`：约 $0.001/张（100 万张以内），返回物体/场景/文本/名人等标签+置信度。
- Azure AI Vision `Tags`：约 $1.5/千次。
- 均以英文词表为主、无风格类标签；适合已有海外云账号且只想要物体级标签的场景。

## 4. 能力与质量对比（面向"图片素材库打标签"场景）

素材库的标签需求以**主体、场景、风格、色调、氛围、构图**为主（现有示例标签如"建筑、氛围、灰调""机械、红色、工业""材质、银色、流体"可佐证）。

| 维度 | 国内视觉大模型（通义/智谱/豆包） | 海外大模型（Gemini/GPT-4o） | 传统 CV 预置识别（百度/腾讯/AWS/Azure） |
| --- | --- | --- | --- |
| 中文标签质量 | 强 | 强 | 中（固定中文词表） |
| 风格/色调/氛围标签 | 强，可用 prompt 约束 | 强 | **基本不支持** |
| 标签粒度可控性 | 强（prompt 指定类别、数量） | 强 | 不可控，仅返回预设词 |
| 置信度输出 | 需 prompt 引导 | 需 prompt 引导 | 原生提供 |
| 结构化输出（JSON） | 通义、智谱、豆包均支持 | Gemini/OpenAI 支持 | 原生 JSON |
| 稳定性/限流 | 通义 RPM 1200 最宽裕 | 受网络环境影响 | 按次计费、稳定 |
| 单张成本 | ¥0.0004～0.002 | ¥0.01～0.04 | ¥0.001～0.0025 |

**结论**：本素材库的标签偏"视觉语言/设计感"，必须选**视觉大模型**而非传统 CV 预置接口；国内大模型在中文、成本、直连三方面综合最优。

## 6. 限流、稳定性与合规

- **限流**：阿里云百炼 qwen-vl-plus 北京区 RPM 1200 / TPM 100 万，10 万张批量可配合 Batch API 异步跑完（数小时级）；智谱、Gemini 免费档限流更紧，验证期够用。
- **批量能力**：阿里云百炼 Batch File 半价；OpenAI Batch API 五折（GPT-4o 折后约 ¥0.013/张）；Gemini Batch 也有折扣——一次性补打存量素材应优先走 Batch。
- **数据合规**：素材图片会传至第三方云。需团队确认素材保密要求；国内服务商（阿里/腾讯/百度/火山/智谱）数据不出境，合规路径简单，且各家承诺不用客户输入做训练（可在控制台关闭训练授权开关）。
- **容灾**：建议主备两家（如通义 + 智谱 FlashX），通过聚合平台（如 302.ai 类多供应商转发）切换成本最低，但数据会经过中间商，敏感素材慎用。

## 7. 选型建议

**推荐组合（主 + 备 + 验证）：**

1. **主力：阿里云百炼 qwen-vl-plus（或 Qwen3-VL-Plus）**
   ——中文标签质量、结构化输出、限流、Batch 半价、国内直连五项均衡。
2. **备份：智谱 GLM-4.6V-FlashX**
   ——单价最低档，作第二供应商容灾与批量压价。
3. **验证期零成本：智谱 GLM-4.6V-Flash（免费）+ 百度"通用物体识别"企业 3 万次免费额度 + 腾讯 1000 次/月**
   ——先跑 100～500 张小样对比标签质量再定主力。

**不建议作为主方案**：百度/腾讯/AWS/Azure 的传统预置识别（无风格类标签）；GPT-4o（贵 10 倍且无额外收益）；Gemini 仅在团队具备稳定海外网络时考虑。

**验证方法（纯调研，不改任何代码）**：取 30～100 张有代表性的素材（覆盖人物、场景、材质、界面、插画等类别），同一批图分别调用 2～3 家 API，输出统一格式（8～15 个中文标签 + 置信度），人工按"准确率 / 风格契合度 / 标签词汇收敛度"三项打分，形成对比矩阵后拍板。建议在验证时同时固定 prompt 口径：

- 标签类别：主体、场景、风格、色调、氛围、构图；
- 数量：8～15 个，按显著程度排序；
- 输出：纯标签列表（或 JSON），不带解释文字。

## 8. 风险与注意事项

- **标签词汇发散**：大模型输出自由度大，数万张图后标签库会碎片化（同义近义词、粒度不一）；需通过 prompt 固定类别体系与粒度，必要时加"参考现有标签库用词"约束。
- **价格波动**：本文价格均为 2026-08 调研时点信息，各家促销/调价频繁，正式采购前以官网控制台实时价为准。
- **免费额度期限**：百度 3 万次为一次性测试资源、腾讯 1000 次/月每月发放，规划验证周期时注意用尽时机。
- **数据出内网**：团队需书面确认素材可上传第三方云；敏感素材应排除在打标范围外。
- **置信度与误标**：大模型偶发误标（尤其抽象/风格混搭图），建议保留置信度字段用于人工抽查；本次调研不涉及误标处理机制设计。

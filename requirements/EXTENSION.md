# Chrome 扩展「右键保存到素材库」需求确认书

> 状态：已实现（2026-09-01 起，图片 + 视频）。
> 本文只描述扩展的产品行为与用户可见规则；接口契约、清单声明、消息协议、后台会话、数据表与字段等实现事实以 AOCI 认知索引为准（见 §8）。
> 本文与实现不一致时，先查 AOCI 与代码，再更新本文。

## 1. 产品定位

类似 Eagle 的浏览器采集能力，但**只做右键菜单采集**这一个入口：

- **做**：网页图片/视频上右键 →「保存到素材库」→ 确认面板（选项目、填标签等）→ 上传到 artDatabase（视频上传后服务端自动转码）。
- **明确不做**（用户拍板）：拖拽采集（与 Eagle 桌面端冲突，暂缓）、悬停元素出现保存按钮、框选区域截图、保存页面全部素材（批量）、多服务器配置、系统通知、Chrome 商店上架（本地解压加载）。

## 2. 用户流程

```
网页图片/视频上右键
  → 菜单「保存到素材库」（仅图片/视频元素上出现）
  → 扩展下载素材（不受页面跨域限制）
  → 校验格式与大小（图片 ≤50MB / 视频 ≤200MB）
  → 全局查重
      ├─ 重复 → 页面内 toast「已存在，未保存」，流程结束（不弹面板）
      └─ 不重复 → 当前页面注入浮动确认面板
            → 用户选项目、编辑标签/名称/来源/备注、（图片可）AI 打标
            → 保存 → 上传（携带插件令牌）
                  ├─ 成功 → toast「已保存到项目X」，关闭面板
                  ├─ 竞态重复 → toast「已存在，未保存」
                  └─ 失败 → toast 失败原因
```

## 3. 确认面板规格

- **形态**：页面内注入的浮动面板，样式与宿主页面完全隔离；可关闭（取消/关闭/遮罩/Esc 均可）。
- **必选字段**：项目下拉，默认记住上次使用的项目；加载失败显示错误并可点重试。
- **可编辑字段**（全部可改，默认值自动填充）：
  - 名称：默认取图片 `alt` → `title` → 文件名（去扩展名）→「未命名-时间戳」；超出服务端长度上限时截断。
  - 标签：逗号分隔输入框；联想已有标签字典；上限 50 个。
  - 来源链接：默认当前页面 URL，可编辑（仅允许 http/https）。
  - 备注：默认为空。
- **预览**：图片显示缩略预览；视频只显示占位（图标 + 大小 + “上传后自动转码”），不传输大字节。
- **AI 打标按钮**：仅图片显示（建议标签合并进标签框，不提前落库）；**视频隐藏**（服务端拒绝视频打标）。
- 取消/关闭面板 = 放弃本次采集，不产生任何记录。

## 4. 认证方案

**背景**：浏览器会话 Cookie 不能用于扩展从任意网页发起的跨站请求，因此扩展改用个人「插件令牌」。

- **令牌管理**：登录用户在顶部用户菜单 →「插件令牌」生成/吊销自己的令牌（可填备注）；明文只在生成时展示一次；列表展示创建时间与最后使用时间。
- **等效身份**：请求携带 Bearer 令牌时与浏览器登录等效，身份为该令牌所属用户，上传等操作归属本人；伪造、已吊销或用户被停用/删除返回 401。
- **有效期**：令牌无过期时间，只能吊销。
- **扩展侧**：设置页填写服务器地址（默认 `http://localhost:3000`）与令牌，并提供「测试连接」；未配置时点击右键菜单会提示去设置页（toast 内「去设置」可直达）。

## 5. 边界与限制

- **仅图片/视频元素**：CSS 背景图、`<canvas>`、内嵌 SVG 不支持；懒加载元素（`src` 为空）无法获取。
- **图片**：JPEG/PNG/WebP/GIF/SVG/TIFF/HEIC/HEIF，≤50MB，与服务端格式白名单一致。
- **视频**：mp4/webm/mov/mkv/avi/mpeg/3gp，≤200MB，与服务端白名单一致；上传后服务端自动转码；视频不支持 AI 打标。
- **URL 形态**：`http(s):`、`blob:`、`data:` 均尽力支持。
- **下载失败**（防盗链/跨域/网络）→ toast 失败原因。
- **竞态兜底**：查重与上传之间被他人抢先时，仍按重复处理并提示「已存在，未保存」。
- **多用户**：令牌绑定个人账号，任何登录用户都可生成自己的令牌。

## 6. 验收清单

- [ ] 开发者模式加载扩展目录，无声明报错；
- [ ] 设置页填服务器地址 + 令牌，「测试连接」显示当前身份；
- [ ] 网页端「账号设置 → 插件令牌」：生成（明文仅显示一次）→ 列表出现 → 吊销后列表消失；
- [ ] 网页图片上右键 →「保存到素材库」→ 面板弹出、预览正确；
- [ ] 重复采集同一张图：不弹面板，toast「已存在，未保存」；
- [ ] 选择项目 + 填标签 + 改名称/来源/备注 → 保存 → toast「已保存到项目X」，素材库出现该图且来源链接=页面 URL；
- [ ] 下次打开面板默认选中上次项目；
- [ ] 点「AI 打标」→ 建议标签合并进标签框（未配置 AI 服务时显示明确错误）；
- [ ] 右键 GIF/SVG/TIFF/HEIC 图片 → 正常进入面板并可保存；
- [ ] 网页视频上右键 → 面板显示视频占位，无 AI 打标按钮；
- [ ] 保存视频 → 上传成功；转码完成后可播放（转码期间显示“处理中”）；
- [ ] 视频 >200MB / 图片 >50MB → 超限提示；
- [ ] 篡改令牌后右键 → 提示「令牌无效或已过期」且可点「去设置」；
- [ ] 网页端登录过期/退出不影响扩展（令牌独立）；吊销后 401。

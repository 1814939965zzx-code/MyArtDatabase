# artDatabase 维度预览 Hover 与深度遮挡交互修订

> 文档版本：v0.19
> 文档日期：2026-08-17
> 状态：已完成

## 1. 更新背景

三维维度预览中，图片经过旋转、透视和面向摄像机变换后，实际屏幕位置可能与浏览器对 CSS 3D 元素的原生指针命中区域不一致。这会导致远端图片 Hover 失效，或者 Hover 命中图片后，按下拖动却被识别为视角旋转。

同时，Hover 图片放大后可能与更靠近摄像机的图片重叠。此时不应通过二维 `z-index` 修改三维排序，也不应改变素材的维度坐标。

## 2. 交互规则

- 鼠标移入某张图片时，该图片在原三维坐标上放大至 `1.65` 倍，并增加阴影反馈。
- Hover 命中以图片投影后的屏幕矩形为准，不依赖 CSS 3D 元素的原生 `:hover` 命中。
- 多张图片在鼠标位置重叠时，按当前视角投影后的深度选择最靠前的可见图片。
- 按 Hover 目标放大后的屏幕矩形检测重叠；与该矩形重叠、且投影深度更靠前的图片在 Hover 期间临时隐藏。
- 后方图片、未重叠图片及坐标网格保持原状。
- 鼠标移出视口、开始拖动图片、开始转动视角、滚轮缩放或重置视图时，立即取消 Hover 并恢复所有临时隐藏的图片。
- Hover 放大与遮挡处理只影响显示，不修改 X/Y/Z 维度值，不写入服务端。

## 3. Hover 与拖动命中

- Hover、单击选择和拖动坐标共用同一套屏幕空间命中结果。
- 视口接收指针事件后，先检查鼠标是否位于某张图片的实际屏幕矩形内，再按投影深度选择目标。
- 命中图片时启动图片坐标拖动；未命中图片时才进入三维视角操作。
- 开始拖动后停止 Hover 切换，恢复前方隐藏图片，并由视口持续捕获指针，直到松手或取消。
- 单击且移动距离不超过拖动阈值时，继续打开对应素材详情。

## 4. 实现说明

- `DimensionPreview.tsx` 新增屏幕矩形命中、投影深度比较、Hover 状态和前方遮挡集合管理。
- 图片元素通过 `data-asset-id` 标识素材，通过 `data-screen-depth` 暴露当前投影深度。
- 指针事件统一由 `.scene-viewport` 处理，图片本身不再作为 CSS 3D 原生命中层。
- `hovered` 状态负责放大反馈；`hover-occluder` 使前方重叠图片在 Hover 期间使用 `visibility: hidden` 临时隐藏。
- 隐藏集合同时用于指针命中排除，保证放大目标在 Hover 期间仍能继续接收交互。

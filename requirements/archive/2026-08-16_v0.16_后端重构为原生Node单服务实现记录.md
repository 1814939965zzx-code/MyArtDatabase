# artDatabase 后端重构为原生 Node 单服务实现记录

> 文档版本：v0.16  
> 文档日期：2026-08-16  
> 状态：已完成  
> 依据：[v0.15 后端图片存储去 ResourceSpace 重构](./2026-08-16_v0.15_后端图片存储去ResourceSpace重构.md)

## 1. 本批范围

本批将应用从「Cloudflare Worker + D1 + ResourceSpace」整体迁移为单个原生 Node.js 服务：

- 完全移除 Cloudflare Worker、D1 和 ResourceSpace 依赖。
- 新增 `app/`：一个 Node.js 进程承载 React 前端 + 全部 API + SQLite + 图片存储。
- 前端 React 19 + TypeScript 原样保留，构建链从 vinext（RSC）迁移到普通 Vite SPA。
- 数据库从 Cloudflare D1 迁移到 Node 自带的 `node:sqlite`，表结构保持一致。
- 图片落本地磁盘，缩略图改为服务端 `sharp` 生成，客户端不再生成缩略图。
- 上传不再依赖 ResourceSpace，修复了「上传图片跑不通」的问题。

## 2. 新架构

| 层 | 实现 |
| --- | --- |
| 前端 | React 19 + TypeScript + Vite + Tailwind v4 |
| HTTP 服务 | `node:http`（单进程，接口与前端静态/开发服务合一） |
| 数据库 | `node:sqlite`（SQLite 文件，Node 内置，无额外依赖） |
| 图片存储 | 本地磁盘 + `sharp` 生成缩略图（可插拔模块 `server/storage.js`） |
| 运行时依赖 | 仅 `sharp` + React 等前端库，无框架、无 ORM、无数据库驱动 |

数据表与 D1 时期一致：`projects`、`project_dimensions`、`assets`、`project_assets`、`asset_dimension_values`、`canvases`、`canvas_items`。移除了废弃的 `assets.external_id` 列。

图片目录结构：

```text
app/data/
  app.db            # SQLite 数据库
  media/
    blobs/<id>      # 原图
    thumbs/<id>     # 缩略图（webp，最长边 ≤ 900px）
```

## 3. 目录与文件变化

- 新增：`app/server/index.js`、`app/server/routes.js`、`app/server/db.js`、`app/server/storage.js`、`app/src/*`（前端组件与入口）、`app/test/api-smoke.mjs`、`app/vite.config.ts`、`app/tsconfig.json`、`app/index.html`、`app/package.json`。
- 迁移：原 `apps/web/app/*.tsx` 与 `globals.css` 移动为 `app/src/*`；14 个 API 由 D1 写法重写为 SQLite 写法。
- 删除：`apps/web`（旧 Cloudflare 版）、`apps/imagestore`（临时独立存图服务）、`infra/resourcespace`、`scripts/validation/resourcespace`、`validation-results/resourcespace`。

## 5. 运行方式

开发模式（单进程，前端热更新）：

```bash
cd app
npm install
npm run dev
```

浏览器访问 `http://localhost:3000`。

生产模式：

```bash
npm run build
npm start
```

环境变量：`PORT`（默认 3000）、`DB_PATH`（默认 `data/app.db`）、`STORE_ROOT`（默认 `data/media`）。环境要求 Node.js ≥ 23.4。

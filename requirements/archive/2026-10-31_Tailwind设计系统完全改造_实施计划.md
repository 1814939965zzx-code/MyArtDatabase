## 1. 需求理解

### 1.1 你要的结果

1. **完全改造**，不是"引入 Tailwind 后慢慢用"：现有的手写样式体系整体退役，后续新增界面只能通过设计系统拼装，样式从此**可控**。
2. **三层可控**：
   - **Token**：色值、字体、字号、字重、间距、圆角、阴影、层级、动效、断点，全部集中定义；
   - **通用控件**：按钮、输入、弹窗、Toast、标签、页签、菜单等，行为与外观只在一个地方定义；
   - **各模块控件**：登录、主页、素材库、上传、详情、标签、成员、维度、画板等模块自己的组合控件，复用通用控件拼装。
3. **验收方式**：上述三层都放进「视觉组件」页，**分模块**陈列，可以直接看到、点到、切状态；页面里展示的就是产品里在用的同一个组件，不是另画一套 demo。

### 1.2 本计划对"完全改造"的定义（完成标准）

改造完成时，仓库必须同时满足：

| # | 完成标准 | 验证方式 |
| --- | --- | --- |
| D1 | `app/src/globals.css` 只剩 `@import`，**不再含任何规则** | 文件行数 < 20 |
| D2 | 原 `styles/legacy.css`（现 `globals.css` 的 1,124 行）**被删除** | `Test-Path` 为 false |
| D3 | 除 `styles/tokens.css` 外，`app/src/**` 中 **hex / rgb / 魔法字号为 0** | 守卫脚本 |
| D4 | 所有按钮、输入、弹窗、Toast、标签、页签、菜单、空态、加载态都来自 `ui/` 原语 | 守卫脚本 + 人工 grep |
| D5 | 页面骨架样式只存在于 `styles/modules/*.css`（100% token），或直接使用 Tailwind utility；不再出现未分层的散装 CSS | 守卫脚本 |
| D6 | 「视觉组件」页三分区完整，每个模块有 specimen，且 specimen 引用生产组件 | 人工验收 |
| D7 | `npm run typecheck`、`npm test`、`npm run build` 全部通过 | CI/本地 |
| D8 | 关键页面视觉与改造前一致（允许已确认的 ±1~2px 取整） | 截图对比 + 人工 |

### 1.3 非目标（本次不做）

- 不做视觉重设计：本轮是**等价迁移 + 统一**，配色、字号、密度原则上不变（除非 §13 决策项另行确认）。
- 不改任何 `/api/*` 契约、数据库结构、业务交互、快捷键与手势行为。
- 不做暗色主题（只预留 token 结构，见 §13）。
- 不重构 `extension/`。
- 不引入 Storybook / 组件测试框架（视觉组件页替代）。

### 3.2 分层与构建

```css
/* app/src/globals.css —— 最终形态 */
@import "tailwindcss";
@import "./styles/tokens.css";
@import "./styles/base.css" layer(base);
@import "./styles/modules/layout.css" layer(components);
/* …每个模块一行… */
```

- `tokens.css` 不放进任何 layer（`:root` 变量 + `@theme`）。
- 旧 CSS 在批次 0 先整体进入 `layer(components)`，之后按批次把规则删掉，等价内容迁到 `modules/*.css`（token 化）或 JSX utility。
- 新代码优先 utility；只有"多元素组合的结构样式"（网格、抽屉布局、画布场景）才落到 `modules/*.css`，且该文件内**不允许出现 hex**，只能 `var(--color-*)` 或 `@apply`。
- 批次 9 删除 `legacy.css` 与全部对它的引用。

### 3.3 Token 规范

- 命名：`--color-*` / `--font-*` / `--text-*` / `--radius-*` / `--shadow-*` / `--spacing` / `--ease-*` / `--duration-*` / `--breakpoint-*` / `--z-*`（z 无命名空间，用 `@utility` 暴露）。
- **兼容别名**：`--ink → var(--color-ink)` 等 10 个老变量保留到批次 9，保证旧 CSS 未迁移期间零漂移。
- 语义优先：业务代码只允许用语义 token（`text-muted`、`bg-surface`），不允许用色阶原始值（`text-neutral-500`）——守卫脚本检查 Tailwind 默认色板类名。
- 字号：`--text-*` 覆盖 Tailwind 默认档位，`text-sm = 12px`，必须在 `tokens.css` 注释里写明。
- 动效：统一用 `duration-fast/base/slow` 与 `ease-out-soft`，禁止在 CSS 里裸写 `transition: ... .18s ease`。

### 3.4 代码约定

1. 条件类名一律 `cn(...)`；禁止 `${cond ? "active" : ""}` 拼 class。
2. 禁止动态类名字符串（`handle-${dir}`），必须映射表；确需动态时 `@source inline()` 显式登记。
3. 原语必须透传 `...rest` 与 `className`（`cn` 合并，外部覆盖排最后）。
4. 原语必须 `type="button"` 默认值（避免表单误提交），需 `type="submit"` 时显式传入。
5. 图标尺寸统一走 `size` 变量（14/16/18/20/24），不写裸 px。
6. 所有交互控件必须有 `aria-label` 或可见文字；图标按钮缺 `aria-label` 由守卫脚本报错。
7. 弹窗统一走 `Modal`（portal + 滚动锁 + `Esc` + 焦点还原），页面不再各自监听 keydown。

### 7.1 页面结构

```
视觉组件
├─ 页头：版本、Token 数、组件数、最近更新时间（构建时注入或手写常量）

├─ 01 Token

│   ├─ 圆角 / 阴影 / 层级（叠层示意）/ 动效（可点播放）

│   ├─ 弹窗（可打开真实 Modal；含危险确认）
│   ├─ 反馈（Toast / 撤销 / 内联提示 / 进度 / 加载 / 空态）
│   ├─ 徽标 / 标签 / 页签 / 分段 / 菜单
│   └─ 每个 specimen 带"生产使用位置"标注
└─ 03 各模块控件（按 §6 分 6 组，共 20 张 specimen）
    ├─ 认证与账号（6）
    ├─ 框架与导航（3）
    ├─ 内容浏览（4）
    ├─ 上传 / 详情 / 标签（3）
    ├─ 维度与画板（3）
    └─ 反馈（1）
```

### 7.2 交互与验收能力

| 能力 | 实现 |
| --- | --- |
| 状态切换 | 每张 specimen 顶部放 `SegmentedControl`（默认 / hover 模拟 / 选中 / 禁用 / 加载 / 错误），由 specimen 内部 state 驱动真实组件 props |
| 尺寸切换 | 通用控件区提供 sm / md / lg 全局切换 |
| 打开真实弹窗 | Token 区的"层级"演示可打开一个真实 `Modal`，用于验收遮罩/滚动锁/`Esc` |
| 明暗对比检查 | 每个色板显示 hex 与对比度，低于 4.5 的标红（当前 `muted`、`accent` 白字会被标出） |
| 生产入口标注 | 每张 specimen 标注"用于：全部素材页 / 回收站 / 上传弹窗…" |
| 空态与异常 | 每个模块 specimen 至少含一个空态或错误态 |

### 7.3 页面自身的约束

- 页面只能用 `ui/` 与 token，**不能**引用任何 legacy 类名；它本身就是"设计系统能覆盖全部场景"的证明。
- 页面随应用一起构建，不引入 Storybook 或额外构建链。
- 入口保持现状：顶部用户菜单 →「视觉组件」（当前仅管理员可见，见 §13 决策 7）。

### 8.1 场景样式边界（重要）

- **不转成 utility**（utility 无法表达 `transform-style: preserve-3d`、动态 `--corner-dx` 等）；
- 迁入 `styles/modules/preview-scene.css` 与 `styles/modules/board.css`，文件内禁止 hex/魔法字号，只允许 token 与布局数值；
- 类名保留（`preview-asset`、`stack-plane`、`canvas-item`…），避免影响 JS 选择器与命中逻辑；
- 视觉组件页为这些模块提供"工具条/面板/控件"级 specimen，不试图在页面里复刻 3D 场景（可放静态截图占位）。

### 14.3 守卫脚本规则草案

```
scan app/src/**/*.{ts,tsx}
- /#[0-9a-fA-F]{3,8}\b/                → 除 styles/tokens.css 外报错
- /\b(text|bg|border|ring)-\[[^\]]+\]/ → 任意值报告（人工确认）
- /font-size:\s*\d+px/                 → CSS 内报错（tokens 除外）
- className=.*\$\{                    → 动态拼接报告
- <IconButton(?![^>]*\blabel=)         → 可访问性报告
- /(bg|text|border)-(slate|gray|zinc|neutral|stone|red|orange|amber|yellow|lime|green|emerald|teal|cyan|sky|blue|indigo|violet|purple|fuchsia|pink|rose)-\d{2,3}/ → 默认色板泄漏
```

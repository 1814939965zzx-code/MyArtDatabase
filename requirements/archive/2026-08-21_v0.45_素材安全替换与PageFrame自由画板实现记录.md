# artDatabase 素材安全替换与 Page / Frame 自由画板实现记录

> 文档版本：v0.45
> 文档日期：2026-08-21
> 状态：已完成并上传功能分支；v0.46 平移手势修订已补充

## 1. 阶段目标

本阶段在不丢失既有素材和数据的前提下，完成两组能力：

- 已有素材可以安全替换图片，并改善素材来源链接的查看与编辑方式。
- 自由画板改为接近 Figma 的 Page / Frame 组织方式，并补充重复放置、多选和自动对齐能力。

改动遵循以下边界：

- 不改变已有素材 ID、项目引用和 Metadata 的归属关系。
- 画板删除操作只删除布局实例，不删除左侧项目素材或磁盘原文件。
- 旧数据库升级必须保留全部既有画板实例及其位置、尺寸、层级和旋转数据。
- 先使用隔离的本地测试数据库和媒体目录验证，不直接操作用户的生产数据。

## 2. 已有素材安全替换图片

- 素材详情支持选择本地文件作为替换图片。
- 支持直接从系统剪贴板粘贴图片作为替换候选。
- 替换提交前可通过 `Ctrl/Command + Z` 撤回候选图片。
- 替换后保留素材 ID、名称、描述、备注、标签、来源链接、项目引用、项目维度值和自由画板实例。
- 服务端先写入并校验新文件，再切换数据库记录，成功后才清理旧文件；任一步失败时保留原素材。
- 缩略图随新图片重新生成，原图和缩略图仍使用既有媒体存储方式。

## 3. 素材来源链接

- 素材详情处于展示状态时，来源链接不显示为可编辑输入框。
- 已有链接可以直接点击并在网页中打开。
- 没有链接时通过“+”按钮进入新增状态。
- 已有链接通过“编辑”按钮进入修改状态。
- 链接变化仍保存到既有素材 Metadata，不创建新的后台数据模型。

## 4. Page 与 Frame 画板结构

- 自由画板采用 `Page → Frame → 素材实例`层级。
- 新项目首次进入自由画板时自动创建默认 Page；新 Page 默认包含一个空的 `1920 × 1080` Frame。
- Page 名称和 Frame 名称均可双击修改。
- 一个 Page 可以创建多个 Frame；所有 Frame 均可删除，删除全部 Frame 后仍可通过按钮重新创建。
- Frame 选中后可以移动，并通过八个方向的控制点自由调整大小。
- Frame 没有固定最大尺寸，但会保持足以容纳内部素材的最小尺寸。
- 缩放视图时，Frame 标题保持最小可读尺寸。
- 空 Frame 右键后可直接删除；包含素材实例的 Frame 删除前显示确认弹窗。
- 删除含素材 Frame 时只移除其中的画板实例，项目素材和原文件仍然保留。

## 5. 素材实例与重复放置

- 同一素材可以在同一 Page 中重复放置任意次数，每次放置都有独立实例 ID 和布局。
- 左侧项目素材始终显示，并展示该素材在当前 Page 中的实例计数。
- 右键图片可以只删除当前画板实例，不影响同一素材的其他实例。
- 双击图片继续打开既有素材详情。
- 图片继续支持拖动、缩放、旋转、置顶和置底。

为兼容旧数据，数据库启动时会检测旧 `canvas_items` 表的 `(canvas_id, asset_id)` 唯一约束。检测到旧结构后，在事务中创建新表并复制所有字段，再替换旧表和重建索引。迁移保留：

- 实例 ID；
- 所属 Page 和素材 ID；
- 横纵坐标；
- 宽度与高度；
- 层级和旋转角度。

迁移失败时事务回滚，不删除旧表或旧数据。

## 6. 框选、多选与安全删除

- 在 Page 空白区域按住鼠标左键拖动，可以使用选择框一次选中多张图片。
- `Shift + 点击`可以增加或移除单张图片的选中状态。
- 拖动任意已选图片时，全部已选图片按相同位移整体移动。
- 多选状态只存在于当前前端会话，不写入数据库。
- 多张图片可批量从画板移除；操作前确认数量，并明确提示原素材仍会保留。
- 单击空白区域可取消图片选择。

## 7. 自动吸附与对齐

- 单张图片移动时，可与其他图片及 Frame 的左、右、上、下边缘和水平、垂直中心吸附。
- 多张图片整体移动时，以所有选中图片的整体外框参与吸附。
- Frame 移动时，可与其他 Frame 的边缘和中心吸附。
- Frame 从八个方向缩放时，正在调整的边缘可吸附其他 Frame。
- 只有进入较小的吸附距离后才触发，避免影响自由拖动。
- 吸附过程中短暂显示对齐辅助线，操作结束后立即隐藏。
- 按住 `Alt/Option` 可临时关闭吸附。

## 8. 数据保存范围

- Page 及素材实例布局继续保存在服务端 SQLite 中，并沿用画板修订号和短轮询同步机制。
- Frame 名称、位置、尺寸及素材实例所属 Frame 当前保存在浏览器 `localStorage` 中。
- Frame 本地数据与项目 ID、Page ID 绑定，不修改素材表、项目素材引用或磁盘媒体文件。
- 图片替换是本阶段唯一涉及媒体文件的操作，并采用先写新文件、成功切换后清理旧文件的安全顺序。

## 9. 本地验证

本阶段使用临时数据库和临时媒体目录完成验证：

- TypeScript 类型检查通过。
- Vite 生产构建通过。
- API 冒烟测试通过，覆盖旧画板表无损迁移、同素材重复实例、删除单个实例后保留其他实例及原素材、安全替换图片和回收站流程。
- 浏览器验证同一素材重复添加后实例计数正确。
- 浏览器验证右键删除图片只移除当前实例。
- 浏览器一次框选 5 张图片成功，组合拖动后 5 张图片位移一致，刷新后布局仍保存。
- 浏览器验证图片接近其他图片时准确吸附到相同边缘。
- 浏览器验证 Frame 名称可双击进入编辑状态。
- 浏览器控制台无错误或警告。

## 11. v0.46 平移手势修订

- 修复鼠标位于 Frame 内部时，Page 平移手势被 Frame 或素材实例事件拦截的问题。
- 鼠标中键拖动始终优先解释为平移 Page 视图。
- 按住空格再用左键拖动同样始终优先解释为平移 Page 视图。
- 平移手势在 Frame、Frame 标题、素材实例、图片缩放点和 Frame 缩放控制点上均有效。
- 进入平移手势后，内部元素不处理选择、移动或缩放，不改变素材数据与布局数据。

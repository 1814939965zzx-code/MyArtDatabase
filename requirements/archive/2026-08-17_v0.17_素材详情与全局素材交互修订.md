# artDatabase 素材详情与全局素材交互修订

> 文档版本：v0.17
> 文档日期：2026-08-17
> 状态：已完成

## 1. 本批范围

本批完善素材详情、全部素材页和高风险删除操作的交互：

- 素材详情左侧使用原图预览，图片同时受容器宽、高约束，保持原始比例并完整显示，不允许裁切。
- 打开素材详情后锁定后方页面滚动；右侧详情内容仍可独立滚动。
- 点击图片之外的黑色遮罩区域关闭详情；点击图片本身不关闭；支持 `Esc` 关闭。
- 项目素材详情与全局素材详情均可编辑素材名称、全局标签、描述、来源链接和备注。
- 关闭素材详情时自动提交已修改的素材信息，效果与点击“保存素材信息”一致；校验或保存失败时保持详情打开。
- 全局标签支持添加、修改、删除；项目详情继续支持编辑当前项目全部维度值。
- 素材网格和列表卡片不再展示原始文件名，原始文件名仅在详情中作为只读信息显示。
- “全部素材”标题及素材总数移入顶部栏，并与项目标题采用同一套样式。
- 全部素材页展示所有全局标签；点击单个标签可快速筛选，再次点击取消筛选；标签筛选可与关键词搜索组合使用。
- 移除全部素材页的永久删除说明、全局预览说明和未归档计数。
- 删除已有全局标签或项目维度时，先显示 5 秒倒计时 Toast；倒计时结束后才写入数据库，期间可点击“撤销”。

## 2. 素材详情规则

### 2.1 图片预览

- 详情预览优先请求原图 URL，素材卡片继续使用缩略图。
- 图片使用 `max-width: 100%`、`max-height: 100%` 和等比例缩放，横图与竖图均必须完整可见。
- 禁止使用会裁切图片的 `cover` 展示方式。
- 图片周围黑色区域属于关闭遮罩；点击图片本身不得触发关闭。

### 2.2 可编辑字段

| 字段 | 全局详情 | 项目详情 | 说明 |
| --- | --- | --- | --- |
| 素材名称 | 可编辑 | 可编辑 | 不能为空 |
| 全局标签 | 可添加/修改/删除 | 可添加/修改/删除 | 修改后同步所有引用项目 |
| 描述 | 可编辑 | 可编辑 | 全局 Metadata |
| 来源链接 | 可编辑 | 可编辑 | 全局 Metadata |
| 备注 | 可编辑 | 可编辑 | 全局 Metadata |
| 项目维度值 | 不适用 | 可编辑 | 仅属于素材在当前项目中的位置 |
| 原始文件名、尺寸、大小、格式 | 只读 | 只读 | 系统生成信息 |

## 3. 全部素材页规则

- 顶部栏标题显示为“全部素材 + 素材总数”，不再单独展示大标题区和未归档计数。
- 搜索框保留在顶部栏，支持名称、原始文件名、标签和引用项目名称关键词。
- 全部全局标签在素材区域顶部完整展示，按单个标签快速筛选。
- 标签筛选和关键词搜索使用 AND 组合：素材必须同时满足当前关键词与所选标签。
- 网格/列表切换保留；卡片只展示素材名称、标签和必要状态，不展示原始文件名。

## 4. 延迟删除与撤销规则

- 适用对象：已有全局标签、项目维度。
- 用户点击删除后，不立即调用删除接口；显示“将在 5 秒后删除”的 Toast 和“撤销”按钮。
- Toast 显示对象名称及剩余秒数；倒计时期间待删除标签显示删除线状态。
- 点击“撤销”立即取消计时，不写数据库，并提示“已撤销删除”。
- 5 秒结束后才执行真实删除；成功或失败均给出结果提示。
- 关闭详情或切换页面不取消计时；同一时间只允许一个待删除项，避免多个计时器覆盖。
- 标签删除由服务端根据执行时数据库中的最新标签集合删除指定标签，避免覆盖同时发生的其他 Metadata 修改。

## 5. 主要实现

- 新增复用组件 `app/src/AssetMetadataEditor.tsx`，统一全局详情与项目详情的 Metadata 编辑。
- 新增 `app/src/DeletionToast.tsx`，提供倒计时与撤销交互。
- `ArtDatabaseApp.tsx` 统一管理标签/维度的全局待删除队列，保证跨页面计时继续。
- `/api/assets` 的 `PATCH` 增加 `deleteTag` 操作，按标签名称进行原子更新。
- 工作区与全局素材接口新增 `originalUrl`，详情预览使用原图、卡片使用缩略图。

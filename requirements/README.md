## 版本规则

- `v0.x`：需求澄清、技术验证与 MVP 设计阶段。
- `v1.0`：MVP 范围冻结并通过验收。
- 已归档文档不覆盖原文件；发生实质变化时新增下一个版本。
- 验证结果记录在对应验证文档中，并注明执行日期、环境和证据路径。

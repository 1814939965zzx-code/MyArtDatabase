# artDatabase

面向团队的局域网图片/视频素材库。素材统一保存在全局库中，项目通过引用、项目维度和自由画板组织素材，不会为每个项目复制文件。

应用位于 `app/`，由一个 Node.js 进程同时提供 React 页面、API、SQLite 数据库和本地图片存储。

## 当前版本

当前产品规则更新至 **v0.49**，已包含从素材导入、Metadata 管理、项目维度预览、Page / Frame 自由画板到 AI 自动打标签与标签字典管理的主要工作流。

### 素材与项目

- 支持全局素材库和项目素材的网格、列表浏览。
- 支持按名称、原始文件名、全局标签和引用项目搜索。
- 支持 JPEG/PNG/WebP/GIF/SVG/TIFF/HEIC/AVIF 图片，可通过文件选择、拖放或剪贴板粘贴上传；支持 mp4/mov/webm/mkv 视频上传（≤200MB），服务端自动压缩为低码率 H.264 MP4（720p、≤2Mbps）后在详情内播放，上传与转码均显示实时进度。
- 上传前使用 SHA-256 检测重复文件，服务端自动生成 WebP 缩略图。
- 素材详情支持名称、标签、描述、来源链接和备注；关闭详情时自动保存。
- 已有素材支持通过文件选择或剪贴板粘贴替换图片，确认前可用 `Ctrl/Command + Z` 撤销候选，项目引用、维度值和画板内容保持不变。
- 来源链接默认直接点击跳转，通过“增加”或“编辑”按钮进入修改状态。
- 全局标签使用 Badge 展示，新增时可模糊匹配已有标签或直接创建。

### 项目维度

- 每个项目可创建任意数量的连续维度，界面数值范围为 `-100～100`。
- 一次可选择最多三个维度，分别生成 1D、2D 或 3D 预览。
- 1D 和 2D 中可直接拖动图片修改维度值；3D 不允许通过拖动图片修改坐标。
- 3D 中左键拖动空白区域或图片都会旋转视角，单击图片仍可查看详情；1D、2D、3D 均支持 `空格 + 左键拖动` 平移视图。
- 支持 `35%～280%` 缩放、页面内专注模式、Hover 放大和深度遮挡淡出。
- 3D 预览支持“隔离当前象限”：隐藏其他七个空间象限的图片，绕离摄像机最近的象限中心旋转，并显示该象限对应的三个维度端点名称。

### 自由画板

- 每个项目可以创建、切换、双击重命名和删除多个 Page；每个 Page 可创建多个自由尺寸 Frame。
- Frame 支持选中后移动、八方向缩放、右键安全删除；图片支持拖动、缩放、旋转、层级调整、双击详情和右键移除。
- 同一素材可以重复放置，左侧项目素材显示当前 Page 的实例计数；移除实例或 Frame 不删除素材原文件。
- 可拖动空白区域框选多张图片并整体移动，`Shift` 增减选择；图片与图片/Frame、Frame 与 Frame 在边缘或中心接近时自动吸附，`Alt/Option` 可临时关闭吸附。
- `空格 + 左键拖动`或鼠标中键可从 Frame、图片、标题和缩放控制点上直接平移 Page 视图，不会误触元素操作。
- 素材实例布局持久化并通过短轮询支持局域网同步；Frame 名称、尺寸、位置与实例归属当前保存在浏览器本地。
- 画板和维度预览都会占满页面剩余可用空间。

### AI 打标与标签

- 素材详情可一键“AI 打标”，经 OpenAI 兼容接口（阿里百炼/智谱等）自动生成中文标签，与人工标签合并去重，单素材上限 50 个。
- 标签存于独立字典；AI 建议标签优先复用已有标签（精确匹配 + 模糊候选 AI 裁决）。
- 全部素材与项目素材共用标签筛选（默认 2 行可展开、选中置顶）；标签管理支持重命名、合并、删除与清理未使用。
- AI 服务配置（接口地址/key/模型名）位于标签管理面板内，key 只存服务端；环境变量优先于页面配置。

## 技术结构

- 前端：React 19、TypeScript、Vite、Tailwind CSS v4。
- 后端：原生 `node:http`、Node 内置 `node:sqlite`、Sharp。
- 存储：SQLite 保存结构化数据，原图/视频与缩略图保存在本地文件系统。
- 运行要求：Node.js `>=23.4.0`，建议使用 Node.js 24。

## 本地启动

```bash
cd app
npm install
npm run dev
```

然后访问 `http://localhost:3000`。数据库（SQLite）与图片文件保存在 `app/data/` 下。

## 当前限制

- 支持图片与视频，不支持音频单独素材、批量上传和在线图片/视频编辑。
- 默认用于局域网，暂无用户注册、登录和权限分级。
- 复制项目、画板评论/文字/连线/导出、自定义 Metadata 字段和 NAS 部署形态尚未完成或尚待决策。
